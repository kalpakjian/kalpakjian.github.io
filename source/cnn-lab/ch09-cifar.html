CHAPTER 09 · 實驗八

換成彩色照片（CIFAR-10）

一句話：模型升級後，錯的地方變得很「合理」——全是長得像的類別，不是隨機亂猜。

STEP 01

這個實驗在做什麼

換成 CIFAR-10（32×32 彩色照片），把模型從 3 個 block 加大到 4 個 block，訓練後把整個 10×10 混淆矩陣畫出來。

  • 輸入CIFAR-10，50k 訓練 / 10k 測試（透過 HuggingFace 取得並快取）
  • 操作wide 架構（964k 參數）、15 epochs、batch 512、OneCycle；對 10k 測試圖做預測，統計 10×10 的計數矩陣並按列正規化
  • 輸出混淆矩陣熱圖（格子裡同時標百分比與張數）、每類前 5 名混淆、總準確率 85.7%
  • 判讀看錯誤是否集中在語意相近的類別（cat↔dog、truck↔car），而不是隨機亂猜

STEP 03

解説

CIFAR-10 的錯誤跟 MNIST 完全不同：

  • MNIST 的錯是「筆畫長得太像」（7 和 2 共用一條底線）
  • CIFAR 的錯是「類別本身就很像」（貓和狗、卡車和汽車）

就像考試把「貓」寫成「狗」、「卡車」寫成「汽車」——你幾乎不會把貓寫成「飛機」。所以 85.7% 看起來不高，但錯誤的分布是合理的：它在該猶豫的地方猶豫。

STEP 04

學到什麼

看準確率之前，先看混淆矩陣。錯在哪裡，比錯多少更重要。而這一章也埋下下一章的伏筆：bird → plane 只有 4%，但它是最可疑的那一種錯。

STEP 05

程式碼

confusion_probe.py · 建矩陣（節錄：略過繪圖）

混淆矩陣沒有神祕公式：cm[真值, 預測] += 1，再按列正規化成百分比。每一格同時印出百分比與張數，才不會被「1 張 = 100%」騙。

_, labels, preds, _ = scan_predictions(model, test_dl, device)

n = len(classes)                                    # 10
cm = torch.zeros(n, n, dtype=torch.long)
for t, p in zip(labels.tolist(), preds.tolist()):
    cm[t, p] += 1                                   # cm[真值, 預測]

acc = (labels == preds).float().mean().item()
rown = cm.float() / cm.sum(1, keepdim=True).clamp(min=1)     # 每列加起來 100%

for i in range(n):
    for j in range(n):
        v = float(rown[i, j])
        if v >= 0.01:                                # 小於 1% 不標，否則整張圖都是字
            ax.text(j, i, f"{v * 100:.0f}\n({int(cm[i, j])})",
                    ha="center", va="center", fontsize=6.5)

「誰最常被認成誰」的排行也是同一份矩陣算出來的：

off = [(float(rown[i, j]), classes[i], classes[j])
       for i in range(n) for j in range(n) if i != j]
off.sort(reverse=True)
for v, t, p in off[:8]:                              # 前 8 名
    print(f"{t} -> {p}: {v * 100:.1f}%")            # bird -> deer: 5.4%

python confusion_probe.py --ckpt run_wide\cifar10\best.pt --class bird --tag wide
