CHAPTER 10 · 實驗九

反事實：只改背景，答案就變了

一句話：同一隻鳥，只把背景換顏色，模型就從「飛機」變成「鳥」。

STEP 01

這個實驗在做什麼

不動模型、不重訓，只改圖片：把最外圈 6 像素的邊框換成不同顏色、或把中心的物件整個蓋掉，再看預測怎麼變。

  • 輸入300 張「真值是鳥」的測試圖；另外單獨取出 42 張「被判成飛機」的子集
  • 操作生成 5 種變體（原圖 / 灰框 / 綠框 / 天空藍框 / 蓋掉中心 20×20），每種各跑一次 forward
  • 輸出每種條件的預測分布、bird 準確率、標籤翻轉率
  • 判讀翻轉率越高 → 越依賴被改動的那塊區域；若蓋掉物件仍能答對，代表它在看背景

STEP 03

解説

這是整份專題最有力的一個實驗：我們沒有動那隻鳥一根羽毛，只改了背景。

  • 把背景從「天空」換成「綠色草地」→ 79% 的誤判被修好
  • 把背景染得更像天空 → 88% 繼續判成飛機
  • 把鳥完全蓋掉，居然還有 56.7% 答對（300 張裡）

最後那一條最恐怖：它證明模型有一部分是看著背景在作答，不是看著鳥。

STEP 04

學到什麼

想證明「模型靠背景」，最直接的方法不是看熱點圖，而是把背景換掉看答案會不會變。這也否定了我們中途的另一個猜想（「這是 32×32 的資訊上限」）——如果只看物件，換顏色不可能讓 79% 的答案翻轉。

STEP 05

程式碼

background_swap.py · 五種條件（節錄）

整個反事實實驗只有兩個「塗抹」函式：一個塗外框、一個塗中心。顏色要先換算成模型看到的正規化數值，否則等於沒改。

def fill_tensor(rgb, cfg):
    """把畫面上的顏色換算成模型看到的正規化數值。"""
    m = torch.tensor(cfg["mean"], dtype=torch.float32)
    s = torch.tensor(cfg["std"], dtype=torch.float32)
    return (torch.tensor(rgb, dtype=torch.float32) - m) / s

def apply_ring(x, fill, b):
    """只塗外圈 b 像素的邊框（物件不動）。"""
    y = x.clone()
    f = fill.view(1, -1, 1, 1)
    y[:, :, :b, :] = f
    y[:, :, -b:, :] = f
    y[:, :, :, :b] = f
    y[:, :, :, -b:] = f
    return y

def apply_center(x, fill, b):
    """把中心正方形（物件）整個蓋掉。"""
    y = x.clone()
    y[:, :, b:-b, b:-b] = fill.view(1, -1, 1, 1)
    return y

def build_conditions(cfg, border):
    gray  = fill_tensor(0.5, cfg)                    # 灰
    grass = fill_tensor((0.28, 0.42, 0.16), cfg)     # 綠色植被
    sky   = fill_tensor((0.45, 0.62, 0.88), cfg)     # 更像天空
    return {
        "original":     lambda x: x,
        "ring->gray":   lambda x: apply_ring(x, gray, border),
        "ring->green":  lambda x: apply_ring(x, grass, border),
        "ring->sky":    lambda x: apply_ring(x, sky, border),
        "center->gray": lambda x: apply_center(x, gray, border),
    }

量三件事：還答對幾 %、標籤被改掉幾 %、以及預測分布變成什麼樣子。

for name, fn in conds.items():
    p = model(fn(x0)).softmax(1).argmax(1)           # x0 = 同一批原圖
    acc[name]  = float((p == cidx).float().mean())   # bird 準確率
    flip[name] = float((p != base_pred).float().mean())   # 標籤改變率
    dist[name] = torch.bincount(p, minlength=len(classes)) / len(p)
