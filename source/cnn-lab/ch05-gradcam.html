CHAPTER 05 · 實驗四

Grad-CAM：模型看哪裡？

一句話：Grad-CAM 會畫出「這張圖的哪些區域，對這次判斷最有貢獻」——但它只能提出假設，不能當結論。

STEP 01

這個實驗在做什麼

對每張測試圖算一次 Grad-CAM：用梯度當「每個通道多重要」，乘上特徵圖後加總，再放大回原圖大小，得到一張熱點圖。

  • 輸入測試圖 + 訓練好的模型
  • 操作forward 取 conv3 特徵 A、backward 取梯度；w = 梯度的空間平均；CAM = ReLU(Σ w·A)；用雙線性插值放大到 32×32
  • 輸出原圖 / 熱點 / 疊圖 三連拍，並標上預測類別與信心
  • 判讀紅=支持這個答案、藍=反對；但 7×7 放大到 32×32，一格代表 4×4 像素，位置誤差 ±4px
STEP 02

數字

樣本熱點位置當時的預測
貓（答對）臉、耳朵cat 80.6%
船（答對）上層艙頂ship 97.4%
船（答錯）紅色船身、水線car 81.4%
鳥（答錯）整張幾乎空白，只剩天空plane 98.3%
STEP 03

解説

Grad-CAM 像「事後問模型：你剛剛是看著哪裡回答的？」

但有一個大陷阱：我們把最後一層（只有 7×7）放大到 32×32。等於「一格代表 4×4 個原始像素」，位置誤差可以到 ±4 像素。

就像用馬賽克照片去猜「他剛剛看哪裡」——馬賽克格子太大，紅點壓在天空，可能只是因為天空離鳥只有一格。

STEP 04

學到什麼

Grad-CAM 的正確用途是產生假設（「它好像在靠天空」），然後用別的方法驗證（第 6 章的遮擋、第 10 章的反事實）。把它當成鐵證，就會像我們一樣在後面被打臉。

STEP 05

程式碼

inspect_model.py · grad_cam()

Grad-CAM 的算式可以濃縮成四步：梯度取平均當權重 → 乘回特徵圖 → ReLU → 放大回原圖。注意放大那一步：7×7 → 32×32 就是位置誤差 ±4px 的來源。

def grad_cam(model, x, layer="conv3"):
    conv = conv_of(model, layer)                  # 取 conv2 或 conv3
    feats, grads = {}, {}
    h1 = conv.register_forward_hook(lambda m, i, o: feats.__setitem__("a", o))
    h2 = conv.register_full_backward_hook(lambda m, gi, go: grads.__setitem__("g", go[0]))

    model.zero_grad(set_to_none=True)
    logits = model(x)
    pred = logits.argmax(1)
    rows = torch.arange(len(x), device=x.device)
    logits[rows, pred].sum().backward()                 # 只對「預測類別」的分數反傳
    h1.remove()
    h2.remove()

    a = feats["a"].detach()                             # (N, C, h, w) 特徵圖 A
    g = grads["g"].detach()                             # 同一位置的梯度
    weights = g.mean(dim=(2, 3), keepdim=True)          # w_c = 梯度的空間平均
    cam = F.relu((weights * a).sum(1, keepdim=True))    # ReLU：只留正貢獻
    cam = F.interpolate(cam, size=x.shape[-2:], mode="bilinear", align_corners=False)
    cam = cam.squeeze(1)
    lo = cam.amin(dim=(1, 2), keepdim=True)
    hi = cam.amax(dim=(1, 2), keepdim=True)
    cam = (cam - lo) / (hi - lo + 1e-8)                # 歸一化到 0..1
    return cam.detach().cpu(), pred.detach().cpu(), logits.detach().cpu()
