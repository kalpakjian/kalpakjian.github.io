CHAPTER 03 · 實驗二

MNIST：越深的層看得越抽象（但越不準）

一句話：越深的層看得越「大」、越「抽象」，但位置也越不精確。

STEP 01

這個實驗在做什麼

訓練 MNIST 3 個 epoch，然後把三層的特徵圖印出來（每層挑平均活化最強的 8 個通道），看同一張圖在三層裡「長什麼樣」。

  • 輸入MNIST 60k 訓練 / 10k 測試，28×28 灰階
  • 操作AdamW + OneCycle，batch 128、3 epochs；用 forward hook 攔截 conv1/2/3 的輸出
  • 輸出三張 4×8 的特徵圖網格（28×28 / 14×14 / 7×7）＋測試準確率 98.9%
  • 判讀響應區域的「尺度」隨層變大、位置隨層變粗——這就是用空間換語意
STEP 02

數字

項目數值
訓練時間15 秒 / epoch（RTX 4090）
準確率演進91.5% → 98.4% → 98.9%

STEP 03

解説

你可以把三層想成三個近視程度不同的人在看同一張紙：

  • 第 1 層像貼很近看：只看得到一小段線條，但位置很準。
  • 第 2 層像站遠一步：看得出「這是個轉角」，但已經說不出「在左邊第 3 公分」。
  • 第 3 層像瞇著眼看：只知道「這裡好像有個圈」，位置只剩下大概。

所以「越深越聰明」是對的，「越深越精確」是錯的。

STEP 04

學到什麼

這件事後面會變成一個大麻煩：當我們用第 3 層做 Grad-CAM（第 5 章），熱點圖會糊掉——因為那一層本來就沒有精確位置。看到「熱點落在天空」，可能只是解析度不夠，不是模型真的在看天空。

STEP 05

程式碼

inspect_model.py · 取特徵圖（節錄）

不用重訓：載入 best.pt，用 forward hook 一次抓三層的輸出，再挑「平均活化最強」的 8 個通道畫成網格。

# nn.Sequential 的位置：0=conv1 2=conv2 4=conv3
LAYER_INDEX = {"conv1": 0, "conv2": 2, "conv3": 4}

@torch.no_grad()
def grab_features(model, x, names):
    feats = {}
    handles = [
        conv_of(model, n).register_forward_hook(
            lambda m, i, o, k=n: feats.__setitem__(k, o.detach().cpu()))
        for n in names
    ]
    model(x)                     # 一次 forward，三層都有
    for h in handles:
        h.remove()
    return feats

feats = grab_features(model, x, ["conv1", "conv2", "conv3"])
for layer in ("conv1", "conv2", "conv3"):
    f = feats[layer]                                          # (N, C, H, W)
    order = f.mean(dim=(0, 2, 3)).argsort(descending=True)[:8]  # 活化最強的 8 個通道
    h, w = f.shape[-2:]
    print(f"  {layer}: {f.shape[1]}ch {h}x{w}")                  # conv1: 32ch 28x28 → conv3: 128ch 7x7

執行方式（--dump-maps 會順便存每張圖的 32 張灰色特徵圖）：

python train_cnn.py --dataset mnist --epochs 3 --dump-maps --plot
python inspect_model.py --dataset mnist --n 4
