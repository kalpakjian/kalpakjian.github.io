> <strong>一句話版本</strong>：Grad-CAM 用「類別分數對特徵圖的梯度平均」當每個通道的重要性，加權疊加後 ReLU，得到一張「模型在看哪裡」的熱圖。

系列第八篇。上一篇（[CAM](/cnn-cam/)）要求末端是 GAP + Linear；這一篇講**把權重換成梯度**之後，
為什麼幾乎任何 CNN 都能用——以及它什麼時候會騙你。

四張圖：七步流程、三張梯度圖的手算、選哪一層、以及「熱圖漂亮不代表看對」。

實測數字（NumPy 2.5.4 / Python 3.15.1，程式與原始輸出在文末附錄）：

- **梯度平均**：`[[0.2,0.4],[0.1,0.3]]` → `α₁ = 0.25`；三張圖的 `α` 是 `0.25 / 0.10 / −0.20`
- **加權疊加**：`L = [[2.6, −0.3], [2.1, 0.2]]`，ReLU 後 `[[2.6, 0], [2.1, 0.2]]`（4 格去掉 1 格）
- **與 CAM 的差別**：同一組特徵圖換成 CAM 的權重（0.8 / 0.1 / −0.2）→ `[[8.1, −0.3], [6.5, 1.3]]`，兩張圖不同
- **等價條件**：純 GAP + Linear 時 `Grad-CAM = ReLU(CAM/(H·W))`，實測最大差 **8.89e-18**
- **一旦中間插 ReLU**：`α = [0.0645, −0.0137, 0.0125]` vs `w/(H·W) = [0.0938, −0.0438, 0.0250]`——不再相等（解析梯度已用中心差分驗證，差 4.38e-11）
- **上採樣**：7×7 的 49 個值 → 224×224 的 50,176 像素（×32），不會產生新資訊

另外整理了六個常見誤解，其中兩個最常被搞錯：**要用 softmax 前的 logit**（機率飽和後梯度太小），
以及**熱圖只說「哪裡」，不證明「看對」**（亮在背景草地就是捷徑特徵）。
