## 重點：這套教材的結構原則

**「原理不會過期，但安裝指令、套件版本、錯誤訊息每年都不一樣。」**

所以整份教材分成兩層：

- **主體（第 1～10 課）**：只寫不隨時間變化的原理。
  不寫版本號、不寫安裝指令、不寫平台路徑、不寫介面步驟。
- **附錄 A～E**：所有會過期的東西集中管理，**每條都標查證日期**。
  - **附錄 A** 本機環境建置（含環境快照）
  - **附錄 B** **實作問題記錄簿**（15 筆實測踩坑，只增不刪）
  - **附錄 C** 版本與 API 變更對照
  - **附錄 D** 指令／參數／路徑速查
  - **附錄 E** 資料集與程式清單（含 11 項實測數據）

## 每個原理都有實測數字

十課的示範全部**在本機實跑過**，關鍵數字直接寫進內文（不是理論值）：

- **RMSE 對極端值的敏感度**：誤差放大 20 倍 → RMSE 放大 **8.99 倍**、MAE 只放大 **4.80 倍**
- **Accuracy 的謊言**：正類只佔 4.5% 時，「什麼都不做」的 Accuracy 有 **0.9545**，
  而模型 Recall 只有 **0.1209**（87.9% 的正類沒抓到）
- **前處理洩漏**：目標欄位是**純隨機雜訊**，用全部資料挑特徵竟做出 **R² = 0.2977**
- **CV 選擇偏誤**：完全沒有訊號的資料，CV 報出 **0.6144**，測試只有 **0.5033**；
  而且樂觀差距隨搜尋預算單調上升（**+0.0233 → +0.0900 → +0.1111**）
- **集成的邊際**：單一深樹標準差 **0.0265** → Bagging **0.0090** → Boosting **0.0012**；
  但同一份資料上 **Ridge 0.6465 勝過所有集成**
- **PSI 的樣本數限制**：n=300 時，**完全沒有位移**的兩組資料 PSI 就可能高達 **0.09～0.15**

## 抓到的坑都記在附錄

實作過程踩到的問題集中在**附錄 B**，包含：

- `ModuleNotFoundError: No module named 'pkg_resources'`（相依鏈與新版 setuptools 的衝突）
- `TimeoutError: No valid workers found`（Windows 多進程需要可匯入的主模組）
- **重導向輸出時中文亂碼**（位元組層級確認：預設用系統 ANSI 碼頁，`PYTHONUTF8=1` 才變 UTF-8）
- **PSI 在小樣本下不可靠**（本課實測發現）

記錄格式固定：**症狀（原始錯誤訊息）／根因／解法／狀態**，只增不刪。

## 建議使用順序

1. 先讀**第 1～4 課**（原理基礎：定位、指標、資料）
2. 讀**第 5～7 課**（搜尋與集成：真正決定分數的地方）
3. 讀**第 8 課**（雲端取捨，概念層）
4. 讀**第 9～10 課**（信任與落地）
5. 動手時才翻**附錄 A**（建環境），卡住時查**附錄 B**
