[deeplearningbook.org](https://www.deeplearningbook.org/) 是 Goodfellow、Bengio、Courville 三人寫的《Deep Learning》（MIT Press, 2016），中文圈叫它「花書」。它免費公開在網路上，但**讀起來很痛**：同一頁裡同時出現線性代數記號、機器學習的評估語言，還有「為什麼這個東西訓練不起來」的工程直覺。

我把 21 個單元（導論 ＋ 第 1–20 章）重寫成一份**正體中文導讀**，補上 **14 張手繪 SVG 圖表**、**20 張霓虹章節插圖**（每章一張，本機 Qwen-Image 2.1 生成）與 **40 題互動測驗**，做成單一 HTML 檔，離線可讀。

## 先說清楚：這不是譯本

原文的線上 HTML 版是 MIT Press 合約下的形式（作者自己稱之為「弱 DRM」），著作權屬於作者與出版社；官網 FAQ 也寫明**中文翻譯權已由人民郵電出版社取得**。

所以這份導讀做的是三件事，而不是全文翻譯：

1. **逐章重寫概念脈絡**——每個單元壓成「一句話 ＋ 一張表 ＋ 幾個必須分清楚的詞」
2. **公式只留骨架**——保留「哪一項在做什麼」，完整推導請對照原書
3. **圖全部重畫**——14 張 SVG 用 Python 產生器輸出、內嵌在頁面裡，沒有一張來自原文

## 14 張 SVG 圖表

圖表用「手繪 SVG」而不是 AI 生圖——因為圖上有中文標籤，AI 生圖的中文字形會爛成方塊。每張圖都是產生器腳本輸出，座標抽成常數，要改一個字只要改一行。

幾張的設計意圖：

| 圖 | 意象 |
|---|---|
| 全書地圖 | 三欄並排的章節卡，一眼看出 Part I／II／III 的分工 |
| XOR | 左邊一條直線切不開、右邊兩條線夾出帶狀區域 |
| 梯度下降 | 同一個碗、同一起點，三種學習率的軌跡 |
| 卷積 | 6×6 輸入 → 3×3 濾波器 → 4×4 輸出，示範參數共享 |
| RNN | 時間軸攤平的鏈，加上梯度衰退的柱狀圖 |
| MCMC | 雙峰分布中間那條跳不過去的谷 |
| ELBO | log p(x) 拆成「可算的」與「≥ 0 的」兩塊 |

量測方式：用本機 Chrome 的 `getBBox()` 逐張量文字邊界（0 問題），再 2× 放大目視檢查「文字有沒有壓到圖形」——後者是量測的盲區，不能省。
