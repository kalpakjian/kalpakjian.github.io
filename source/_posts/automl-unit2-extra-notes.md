## 這份課節的核心：混淆矩陣是唯一的起點

四個格子（TP / TN / FP / FN）決定了後面所有指標的性格：

| 指標 | 公式 | 它最在乎什麼 |
|---|---|---|
| **Accuracy** | (TP+TN) / 全部 | 類別均衡時才好用 |
| **Precision** | TP / (TP+FP) | **FP**——不要冤枉好人 |
| **Recall** | TP / (TP+FN) | **FN**——不要漏掉壞人 |
| **F1** | 2PR/(P+R) | 兩邊都要顧，任一邊塌掉就沒分 |

所以題目給你一個場景，問「該用哪個指標」，答案永遠從「**這個場景最怕 FP 還是最怕 FN**」推出來。

回歸那一半也一樣乾淨：**MAE 線性計分、對離群值容忍；RMSE 先平方再開根號，特別討厭離譜的大失誤；R² 則把評估標準化，0 代表「跟全猜平均一樣爛」，負值代表比全猜平均還糟。**

| 主張 | 實測數字 |
|---|---|
| 不平衡資料下 Accuracy 會騙人 | 10,000 個細胞、10 個癌，全猜健康 → Accuracy **0.999000**、Recall **0.000000** |
| 調門檻無法同時最大化 P 與 R | 門檻 0.5→3.5：Precision 0.0286→1.0000，Recall 0.9000→0.1000；F1 最高落在門檻 **2.5**（0.3467） |
| MAE 相同、RMSE 可以差很多 | `[5,3,4]` → MAE 4.0000 / RMSE **4.0825**；`[1,1,10]` → MAE 4.0000 / RMSE **5.8310** |
| R² 可以為負 | 完美 **1.000000**、全猜平均 **0.000000**、比平均更糟 **−1.132762** |
| 手肘法與輪廓係數會指向同一個 K | inertia 降幅在 K=4→5 由 **1569.9** 崩到 **19.5**；輪廓係數 K=4 最高 **0.8756** |

| `max_iter` 被切斷不會報錯 | max_iter=5 → inertia **4892.0**；正常收斂 28 次 → **4389.2** |

## K-Means 的三個必考細節

1. **目標函式是最小化 WCSS（inertia）**，而 inertia 隨 K **單調遞減**——所以「選 inertia 最小的 K」是錯的，要看**降幅的轉折點**。
2. **距離用歐幾里得、各維度差值平方後相加**，所以執行前**必須**先 `StandardScaler`，否則「體重 60,000 公克」會壓過「身高 170 公分」。
3. **只保證局部最佳解**，結果受初始化影響。scikit-learn 預設 `init='k-means++'`（不是隨機），而且要檢查 `n_iter_ < max_iter` 才算真的收斂。
