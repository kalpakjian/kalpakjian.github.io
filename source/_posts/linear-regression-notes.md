## 這份課節的核心：一行公式，四個角色

$$y = ax + b$$

| 角色 | 符號 | 一句話定義 | 課程的例子 |
|---|---|---|---|
| 輸入 | $x$ | 我們已知、能掌握的資料 | 讀書時數 |
| 輸出 | $y$ | 我們想預測的結果 | 考試分數 |
| 斜率 | $a$ | 輸入每增加一單位，預測結果改變多少 | 每多讀 1 小時多 5 分 |
| 截距 | $b$ | 輸入為零時，直線上的預測結果 | 沒讀書時的預測基本分 |

整份課節的骨架就是：**先認得這四個角色 → 再看斜率與截距怎麼各自控制直線 → 最後把數字代進去**。

課程用「**旋鈕**」比喻 $a$ 與 $b$：轉 $a$ 改變角度（方向與陡度），轉 $b$ 整條線上下平移。而改變輸入 $x$ 只是**在同一條線上移動**——這兩件事分清楚，後面才不會亂。

---

## 三個最容易考錯的地方

1. **$a = 0$ 不代表「兩者無關」** —— 正確說法是「**這個線性模型**的預測不隨 $x$ 改變」。關係可能不是直線，或這批資料看不出趨勢。
2. **殘差是「實際值 − 預測值」**（$y - \hat{y}$），不是反過來。順序顛倒會讓正負號全部相反。
3. **$b$ 不一定能解讀成「基本分」** —— 只有當**資料涵蓋 $x = 0$** 時才有觀察支撐，否則它只是把直線往左延伸後的數學交點。

## 我把每一個數字主張都跑成本機數字

筆記裡的公式與主張都附實測輸出（Python 3.11.15 / numpy 2.4.6 / scikit-learn 1.9.1，可完整重現），原始輸出全文收錄在附錄 G：

| 主張 | 實測數字 |
|---|---|
| 課程的示意模型可完全重現 | $y = 5x + 50$ 在 $x = 0..4$ 給出 50／55／60／65／70 |
| $a$、$b$ 真的是「從資料學出來的」 | 電腦從同一組點學回 $a$ = **5.0000**、$b$ = **50.0000**，最大還原誤差 **0.00e+00** |
| 最小平方法真的會挑到最小 | 三條候選線 SSE = 14.0 / 51.0 / 87.0；最小平方法挑出的那條 **12.3000**（比課程那條更低） |
| 平方為什麼不能省 | 殘差 `[10, -10]` 直接相加 = **0.0**（看似完美），平方後 = **200.0**；大誤差被放大 **50 倍** |
| 外推有多荒謬 | 同一個模型丟 $x = 20$ → **150 分**、$x = 100$ → **550 分** |
| 沒涵蓋 $x = 0$ 的代價 | 只用 $x = 3..8$ 配線，截距估成 **48.1238**（真實 50.0，差 1.8762） |
| 彎曲資料硬套直線 | 對 $y = x^2$ 硬套直線 $R^2$ = **0.0000**；改用二次曲線 **1.0000** |

> 第 3 項值得記住：**最小平方法算出來的線，SSE 一定不會比任何其他線更大**。課程那條 $y = 5x + 50$ 是為了教學方便先假設的，不是這批資料的最小平方解——這兩件事不衝突，只是要分清楚「示意」與「配線結果」。
