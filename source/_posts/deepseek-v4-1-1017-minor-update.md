> <strong>整理說明</strong>：本文的數字都在 2026-10-28 對過一輪原始出處——Artificial Analysis 模型頁、DeepSeek 官方 release note（news261017）、Hugging Face 模型卡，以及 9to5AI 的整理。**官方公布值、AA 量測值、我自己的機器實測、社群傳言**四種來源分開標註，不混在一起講。

DeepSeek V4.1 1017 發布一週之後，結論還是那句：性價比之王。

但這篇不是要再吹一次。我原本寫在社群上的版本有幾個數字對不上，趁發到部落格一次改掉，順便把「哪裡是官方說的、哪裡是我猜的」標清楚。

## 三十秒結論

| 項目 | 數字 |
|---|---|
| AA 智力指數 | 39 → **45**（+6） |
| 每任務成本 | $0.32 → **$0.26**（約 −19%） |
| 成本下降來源 | 輸出量 250M → **210M tokens**，API 單價沒動 |
| API 定價 | $0.30 / $1.20 per 1M（cache 命中 98% 折扣，混合約 $0.18） |
| 模型卡寫法 | 就一句「a minor update」 |
| 權重 | MIT；HF 上 763B tensors / 510 GB（AA 記 552B backbone、16B active） |
| 規格 | 1M context、text + image 輸入、tool calling、reasoning |

一句話：**它沒有變便宜，它是變得更省話。** 這比直接砍價健康得多。

## 一、這次到底改了什麼

官方 release note 的標題是「Wish-Driven Programming Made Real」，內容其實不少：

- 官方自報 11 項 benchmark 全部上升，輸出更短、任務完成更快
- 附了四個端到端 demo：紫禁城 3D 建模、網頁賽車遊戲、用 Godot 重製《Portal 2》、從史前到現代的 3D 場景
- 同一天開放 Search / Fetch API：**$0.75 / 1,000 次呼叫**，2026-10-31 16:00 UTC 開始計費（在那之前，Harness / Claude Code / Codex 走 server-side tool 免費）
- API 端 `deepseek-flash` 直接指向 1017，呼叫方式與價格不變

HF 模型卡上的評測（官方自報）：Terminal-Bench 4 **42.3**（Claude Code harness）、DeepSWE 1.1 **77**、HLE **42.6**（無工具）／**44**（純文字子集）、Agents' Last Exam **35.4**。

重點在成本那一行。**單價一毛沒動**，是「跑完 AA 智力指數的輸出量從 250M 掉到 210M」——同樣的分數用更少 token 換到，成本自然下來。這也是為什麼 AA 把它放進 Pareto 前緣：不是靠補貼，是靠效率。

## 二、不是第一次：0731 那次的 +10

七月 V4 → V4 0731，AA 從 **40 衝到 50**，一次 +10，架構、尺寸（284B / 13B active）、價格全部不動。當時模型卡也是一句 minor update。

這裡要先打預防針：**AA 智力指數自己改過版。** 七月的 +10 是 v4.1 版本的指數；現在頁面上的 39 / 45 是 **v4.3.2**（10 項評測，多了 GDPval-AA v2.1、AutomationBench-AA、Terminal-Bench 4.0 等）。所以：

- 39 → 45 這種「同一頁、同一版指數」的比較可以看
- 「0731 的 50 比 1017 的 45 高」這種跨版本比較**不要做**

對照組是 GPT-6 Sol：版號從 5.6 跳到 6，AA 是 **48**（2026-09-22），每任務 **$1.04**。版號通膨是真的；但要說「OpenAI 沒進步」就不必了——5.6 Luna 在當期的指數上就拿到 51。**大版號 ≠ 大進步，小版號也不等於小改動，這句話兩邊都適用。**

## 三、命名邏輯：大版號換架構，日期重做 post-training

DeepSeek 的版本政策（社群轉述，我沒找到官方原文，先當「慣例」看）很乾脆：

- **大版號** = 換架構
- **日期**（0731、1017）= 同一副骨架，重做 post-training

這對地端部署是好消息。post-training 不動架構，代表量化格式、推理引擎、既有的 patch 全部可以沿用，不用每次改版就重跑一輪踩雷。1017 出來隔天，DGX Spark 的跑法就在社群傳開了——這就是「骨架沒換」的實際好處。

反過來說，這也是判斷該不該跟版的依據：**看到日期版，先跟；看到大版號，先等等看量化社群有沒有跟上。**

## 四、我自己實測：兩台 Spark

先聲明，這段是我自己機器上的數字，不是官方數據。

- 硬體：兩台 DGX Spark
- 量化：Mia 的 EXL3 2.9 bpw + TensorFold
- 單串流 **code 115 tok/s、prose 67 tok/s**
- 1M context 跑得動，工具呼叫、Vision 都過

體感就一句話：**日常好用又便宜。** coding 場景特別舒服——不是那種「哇它好聰明」的驚豔，而是你不會中途想換掉它的那種順。

## 五、它到底站在哪一格：別再跟 Sonnet 5.5 比

我原本寫「大小任務都有 Sonnet 5.5 等級，分數也接近」，這句話要收回。

| 模型 | AA 智力指數 | 每任務成本 |
|---|---|---|
| DeepSeek V4.1 Flash 1017 | 45 | **$0.26** |
| GPT-6 Sol (max) | 48 | $1.04 |
| Claude Sonnet 5.5 (max) | **56** | $5.46 |

1017 離 Sonnet 5.5 還有 11 分，而 Sonnet 5.5 貴它 **21 倍**。所以正確的說法是：

> **它的位置在 GPT-6 Sol 腳邊（少 3 分），價格是別人的四分之一。**

要說「體感接近 Sonnet 5.5」可以，那是使用體驗的描述；但**分數不接近，價錢差兩個數量級**。這句話寫清楚，整篇的可信度才守得住。

## 六、為什麼一週之後評價還是偏正

看過太多模型一開始好評如潮，兩週後沒人提。但 DeepSeek 這次一週過去，網路評價還是正面居多。我自己覺得是四個原因：

1. **一開始就沒瞄準 SOTA**，省下很多硬碰硬的力氣
2. **只跟你死磕性價比**，而且是用效率（少講話）而不是補貼
3. **權重 MIT、地端可跑**——這裡要精確：它是 *open weights*，不是連訓練碼與資料都給的 *open source*
4. **不開發表會**：0731 與 1017 都只有一篇 release note

不過第 4 點要打個折。這次的 release note 標題叫「Wish-Driven Programming Made Real」，附四個 demo，同一天還上了 Search / Fetch API 的收費公告。所以更準確的描述是：

> **不辦大會、不喊 V5，但該賣的一個沒少。**

如果用餐飲比喻：Opus 5.5 是米其林法式料理，DeepSeek 不是那種店。它比較像路邊小吃店，但是必比登推介——價錢親民、水準不馬虎，而且食譜公開，讓你在家自己煮。

## 七、兩個我查不到實證的社群說法

我不想把它寫成結論，先掛著：

1. **1017 疑似刻意壓低網安指令能力**，紅隊／滲透測試用途可能不如九月版。官方模型卡與 release note 都沒提，也沒有可引用的第三方評測。
2. **推理框架 DeepInfer 開源**。DeepSeek 官方 news 列表沒有這一項，待確認。

如果第 1 點成立，那會是「開源陣營開始自我抑制資安濫用」的一個有趣訊號——但目前只是傳言。

## 八、要上 production：10/19 之後多了一條合規線

2026-10-19，美國 DHS 的命令禁止聯邦民用機構使用 DeepSeek 產品，**而且包含「以 DeepSeek 為基礎的第三方產品」**。

所以「上正式環境建議自己部署」不再只是口味問題，是合規問題。像 OpenCode 這種有免費額度的方案，拿來嚐鮮很好；但它背後是哪個站台在 serve、資料落到哪裡，我沒查到，正式環境就別賭。

自己架的話，MIT 授權 + 1M context + 固定的 post-training 骨架，反而是這一年少數「升級不用重做基礎設施」的路線。
