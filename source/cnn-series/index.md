這個系列用九篇把一個卷積神經網路從「一張 5×5 的小圖」一路拆到「模型在看哪裡」。
每一篇都是**單一 HTML 檔、零外部資源**，圖表全部是手繪內嵌 SVG（真 `<text>`，可選取、可列印），
而且**頁面上的每個數字都由程式算出來**，原始輸出貼在每篇的附錄 G。

## 三種讀法

| 你有多少時間 | 建議路線 |
|---|---|
| **30 分鐘**（只想搞懂整體） | [1 圖解 CNN](/cnn-illustrated/) → [5 卷積 vs 全連接](/cnn-conv-vs-fc/) → [6 GAP](/cnn-gap-head/) |
| **從頭學一輪**（3–4 小時） | 1 → 2 → 3 → 4 → 5 → 6 |
| **只查可解釋性**（CAM 那一支） | [6 GAP](/cnn-gap-head/) → [7 CAM](/cnn-cam/) → [8 Grad-CAM](/cnn-gradcam/) → [9 兩者對照](/cnn-cam-vs-gradcam/) |

## 九篇一覽

| # | 主題 | 這篇回答的問題 | 一句話重點 |
|:--:|---|---|---|
| 1 | [圖解 CNN](/cnn-illustrated/) | 一張影像怎麼變成「貓 0.93」？ | 8 張圖走完 卷積 → ReLU → 池化 → 攤平 → 全連接 → softmax |
| 2 | [卷積層的運作細節](/cnn-conv-details/) | kernel 的深度、stride、padding、感受野怎麼算？ | 同產出 25,088 個值，卷積只要 320 個參數 |
| 3 | [激活函數與池化層](/cnn-activation-pooling/) | ReLU 到底在做什麼？池化為什麼沒有參數？ | 沒有非線性，多層等於一層（實測差 4.44e-16） |
| 4 | [全連接層的運作](/cnn-fully-connected/) | `z = Wx + b` 與 softmax 的細節 | 參數 97.6% 集中在這裡；softmax 保序、平移不變 |
| 5 | [卷積層 vs 全連接層](/cnn-conv-vs-fc/) | 兩者的差別有多大？ | 同樣產出，參數差 **61,544 倍**、算力差 87 倍 |
| 6 | [GAP 是什麼](/cnn-gap-head/) | 為什麼現代 CNN 不用大 FC？ | 分類頭從 **25,089,000** 降到 **513,000** 個參數 |
| 7 | [CAM](/cnn-cam/) | 怎麼把分類權重變成一張熱圖？ | `mean(CAM) = logit − bias`（實測差 4.44e-16） |
| 8 | [Grad-CAM](/cnn-gradcam/) | 沒有 GAP 的模型怎麼做熱圖？ | 用梯度平均當權重：`α = mean(∂yᶜ/∂A)` |
| 9 | [CAM vs Grad-CAM](/cnn-cam-vs-gradcam/) | 兩者到底差在哪？ | 公式一樣，只差權重是「學來的」還是「算的」 |

## 每篇的規格都一樣

| 項目 | 說明 |
|---|---|
| 格式 | **單一 HTML 檔、零外部資源**，下載後雙擊就能離線看 |
| 圖表 | 全部手繪內嵌 SVG（46 張），文字可選取、`aria-label` 齊全 |
| 數字 | 由 `verify_*.py` 算出並貼在**附錄 G**，可重跑驗證 |
| 附錄 | A 速查表、B 常見錯誤、C 延伸閱讀、D 一頁精華、G 實測原始輸出 |
| 原始檔 | 每頁都可下載 Markdown（側欄「📄 下載原始 Markdown」） |
| 測驗 | [1](/cnn-illustrated/mc-quiz.html) 與 [7](/cnn-cam/mc-quiz.html) 另有 30 題互動測驗（即時計分、進度存瀏覽器） |
