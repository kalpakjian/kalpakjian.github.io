這份課節在講什麼？ → 用「一條直線」描述兩件事的整體關係，並用它估計結果。

【四個角色：一行公式，四個角色】
  y = a x + b
  x ：輸入（自變數）——我們已知、能掌握的資料，例：讀書時數
  y ：輸出（應變數）——我們想預測的結果，例：考試分數
  a ：斜率——x 每增加 1 個單位，預測的 y 改變多少
  b ：截距——x = 0 時，直線上的預測值（起點）

【斜率的長相】
  a > 0 → x 增加，y 上升        a = 0 → x 增加，預測 y 不變（水平線，通過 b）
  a < 0 → x 增加，y 下降        |a| 越大 → 直線越陡
  ⚠️ a = 0 只代表「這個線性模型」的預測不隨 x 改變，不等於現實中兩者無關

【截距的脾氣】
  x = 0 時 ax 消失，只剩 b → 所以 b 是直線的起點
  改變 b → 整條線上下平移，斜率 a 不變；改變 a → 整條線改角度

【課程的示意模型】y = 5x + 50（b = 50、a = 5）
  x = 0,1,2,3,4  →  y = 50,55,60,65,70
  讀 4 小時 → 5 × 4 + 50 = 70 分（是「模型預測」，不是保證考到）

【殘差：資料不會剛好落在線上】
  殘差 = 實際值 − 預測值 = y − ŷ    點在線上方 → 殘差為正；下方 → 殘差為負
  我們要的不是穿過每一個點的線，而是讓整體差距盡量小的線

【最小平方法的三步】
  ① 比較每個差距 → ② 平方後加總 → ③ 找出最小總和（由電腦算）
  平方的兩個作用：正負不會互相抵消、較大的差距被更重視
  「最佳」＝ 殘差平方和最小，不代表這條線適用於所有情況

【使用時的三個提醒】
  ① 相關不等於因果   ② 避免過度外推   ③ 彎曲關係別硬套
  三個自我檢查問題：能否解釋原因？是否超出觀察範圍？關係是否大致筆直？
你會用到的記號 一句話記法
輸入／自變數（independent variable），已知的資料
輸出／應變數（dependent variable），想預測的結果
模型的預測值（y-hat）；課程為求簡潔直接寫
斜率（slope）＝ 變化率，決定走勢
截距（intercept）＝ 起點， 時的預測值
殘差（residual），實際值減預測值
殘差平方和（SSE），最小平方法要最小化的量

1. 從生活出發：生活中處處有「一條直線」

課程不從公式開始，而是先給兩個日常例子，說明「一條直線」為什麼是理解關係的起點。

1.1 課程的兩個生活例子

生活例子 課程的描述 方向
氣溫與冰淇淋銷量 氣溫越高，冰淇淋通常賣得越多 一起上升
讀書時數與成績 讀書時數越多，成績通常越高，但每個人的情況仍會不同 一起上升（但有例外）
炎熱的日子 炎熱的日子，冰淇淋更受歡迎 情境補充

兩個例子都指向同一件事：兩件事會一起變動，而這種「一起變動」可以用一條線來概括。

1.2 線性迴歸的一句話定義

線性迴歸就是用一條直線，描述兩件事的整體關係，並估計可能的結果。

這句話裡有三個關鍵字：

關鍵字 意思 不是什麼
一條直線 用最簡單的形狀概括趨勢 不是穿過每個資料點的曲線
整體關係 看的是全部資料的走向 不是解釋單一個案
估計 給出「可能」的結果 不是保證、不是精確答案

1.3 「通常」這兩個字為什麼重要

課程在描述兩個例子時，都刻意加上「通常」。原因有三層：

  1. 生活中的關係不一定完全筆直 —— 直線只是簡化的描述方式。
  2. 個別情況會偏離趨勢 —— 有人讀得少卻考得好，有人讀得多卻失常；直線描述的是整體，不是每個人。
  3. 趨勢 ≠ 定律 —— 「通常」保留了例外，也提醒讀者不要把模型當成保證。

1.4 為什麼選「讀書時數 → 考試分數」

課程把讀書時數當成主線例子，因為它同時滿足三個條件：

  • 可量化：時數是一個數字，可以拿來運算。
  • 有直覺：多讀一點、分數高一點，幾乎不需要解釋。
  • 有落差：每個人的情況不同 —— 剛好可以說明「趨勢」與「個別差異」的區別。

考點：問「線性迴歸在做什麼」時，正確答案的關鍵字是「整體關係」與「估計」；只答「畫一條線」會漏掉重點。

2. 認識模型：一行公式，四個角色

課程把整個模型壓縮成一行公式，並要求先認得四個角色，而不是先背公式。

2.1 公式：一行公式，四個角色

這一行就是完整的模型。左邊是「我們想知道的」，右邊是「我們已知的」與「模型學到的」。

2.2 四個角色總覽

角色 符號 一句話定義 課程舉的例子
輸入 我們已知、能掌握的資料 讀書時數
輸出 我們想預測的結果 考試分數
斜率 輸入每增加一單位，預測結果改變多少 每多讀 1 小時多幾分
截距 輸入為零時，直線上的預測結果 沒讀書時的預測基本分

2.3 輸入 x：我們已知的那一半

是「已知輸入，就能算出直線上的預測結果」裡的那個輸入。它必須是可以事先取得的資料 —— 先知道讀了幾小時，才可能預測分數；反過來就沒意義了。

2.4 輸出 y：我們想猜的那一半

是模型算出來的結果。課程特別強調： 是「模型產生的預測」，不是實際發生的結果。

2.5 斜率 a：決定方向與陡度

回答的是「輸入每增加一單位，預測結果改變多少」。它同時決定兩件事：

  • 方向： 是正的還是負的（上升或下降）。
  • 陡度： 有多大（變化劇不劇烈）。

2.6 截距 b：決定起點

是「輸入為零時，直線上的預測結果」。把 代進公式， 這一項就消失，只剩 —— 這就是「起點」的來源。

2.7 記號提醒：a、b 不是全世界通用的

常見寫法 斜率 截距 說明
本課程
常見教科書
統計學

三者是同一件事，只是字母不同。另外，嚴謹的統計記號會把模型輸出寫成 （y-hat），以便和實際觀察值 區分；課程為了簡潔，一律直接寫 ，只有殘差那一張圖同時出現兩者。

考點：看到 要能立刻對應到 —— 考題很愛換字母。

3. 先分清楚要用什麼、猜什麼：x 與 y

課程在此把「誰是輸入、誰是輸出」講清楚，因為順序弄反，整條線的意思就完全相反。

3.1 自變數與應變數

角色 名稱 課程的定義 例子
輸入 自變數（independent variable） 拿來解釋或預測的資料 ：讀書時數
輸出 應變數（dependent variable） 我們想了解的結果 ：考試分數

「自變數／應變數」與「輸入／輸出」是同一組概念：自變數餵進去，應變數跑出來。

3.2 課程的搭檔：x 與 y 是「原因與結果的搭檔」

課程用「搭檔」這個詞，是因為兩者在模型裡是綁在一起的：

3.3 兩種「改變」要分清楚

這是初學者最容易混淆的地方，也是後面所有章節的基礎：

你改變的東西 直線上發生什麼 模型有沒有變
只改變輸入 沿著同一條直線移動到另一個點 沒有變（、 不變）
改變斜率 或截距 整條直線換成另一條 變了（換了一個模型）

換句話說：改 是「在模型裡移動」，改 或 是「換一個模型」。

3.4 為什麼「還不能證明誰造成誰」

課程提醒：這裡的搭檔是「預測關係」；光靠一條直線，還不能證明誰造成誰。

原因很單純：模型只負責「一起變動」的數學描述，不負責解釋背後機制。要談因果，需要的是實驗設計或領域知識，不是配一條線。

3.5 考點：斜率為零的那個特殊情況

課程在這一節先埋了一個伏筆：斜率為零時，改變 不會改變模型預測。

  • 這句話說的是「這個線性模型」的預測不變。
  • 它不代表現實中兩件事完全沒有關係 —— 也可能是關係不是直線，或是這批資料看不出趨勢。

考點：「 代表 與 完全無關」是錯的；正確說法是「這個線性模型的預測不隨 改變」。

4.4 課程附帶的一句提醒

斜率描述的是模型中的變化，不代表已證明因果。

這句話和 §3.4 是同一個立場：模型可以告訴你「變多少」，但不能單獨告訴你「為什麼」。

4.5 考點

  • 問「 變大，直線會怎樣」→ 要分開答：正負決定方向， 決定陡度。

8. 直線說趨勢，資料有差距：殘差

前七節都在講「完美的直線」，這一節回到現實：資料不會剛好落在線上。

8.1 殘差的定義

殘差是實際值減去預測值，也就是資料點與直線之間的垂直差距。

注意是垂直差距：同一個 之下，往上或往下量到直線的距離。

8.2 正殘差與負殘差

資料點的位置 計算 殘差
在直線上方 實際值 > 預測值 正
在直線下方 實際值 < 預測值 負
剛好在線上 實際值 = 預測值

課程提醒：用同一個 比較實際值和預測值，才是這張圖在做的事；圖為概念示意，沒有代表任何觀測數據。

8.3 為什麼不是「穿過每一個點」

我們要找的，是讓整體差距盡量小的線，而不是穿過每一個點的線。

這句話點出線性迴歸的核心取捨：

目標 結果
穿過每一個點 通常不可能（除非點剛好共線），而且會變成複雜曲線
讓整體差距最小 一條簡單的直線，代表整體趨勢

8.4 圖上的三個標記

課程用左右兩格圖解釋殘差：

左格：概念散佈圖（示意） 右格：殘差放大說明
散佈點分布在直線上下，以括號標出「殘差」，並標示斜率 與截距 ；座標軸為「分數」與「讀書時數」 標出「實際值（）」「預測值（）」，以及兩者之間的「殘差（）」

8.5 考點

  • 殘差公式是 實際值減預測值（），不是反過來 —— 順序顛倒會讓正負號全部相反。
  • 「殘差」是垂直距離，不是點到直線的最短距離。

9. 讓資料決定直線：最小平方法

前面都是「給定一條線」，這一節回答最關鍵的問題：這條線是怎麼被挑出來的。

9.1 為什麼要平方

最小平方法會把每個殘差平方後加總，選出總和最小的直線。

平方不是為了好看，而是為了解決兩個問題：

問題 如果不平方 平方之後
正負殘差會互相抵消 正 10 與負 10 相加變成 0，看起來「完美」 兩者都變成 100，不會抵消
大失誤和小失誤一視同仁 差距 10 與差距 1 只差 10 倍 差距 10 被放大成 100，是差距 1 的 100 倍

課程的說明是：正負差距不會抵消；較大的差距也會更受重視。

9.2 三個步驟

課程把整個方法拆成編號 01–03 的三步：

步驟 標題 課程的說明
01 比較每個差距 同一個輸入下，比較實際結果和直線的預測
02 平方後加總 正負差距不會抵消；較大的差距也會更受重視
03 找出最小總和 由電腦計算，找出最符合這批資料的設定

流程圖示：

① 逐點算殘差 → ② 每個殘差平方後全部加起來 → ③ 找出讓這個總和最小的 a 與 b

9.3 數學形式：殘差平方和（SSE）

名稱 符號 說明
殘差平方和 或 SSE（Sum of Squared Errors） 越小代表直線越貼近資料
目標 找出讓 最小的 與

「最佳」的定義就是殘差平方和最小 —— 這是相對於這批資料、這個標準而言的最佳，不是絕對真理。

9.4 課程的兩個補充說明

  • 、 是從資料「學」出來的 —— 它們不是人為指定，而是由資料算出來的。
  • 我們先理解比較差距的概念，不必手算整套過程 —— 課程刻意把重點放在「為什麼」，實際最小化交給電腦。

9.5 考點

  • 平方的兩個作用要能同時說出：防止正負抵消、加重較大誤差的權重。
  • 「最佳直線」的定義是 殘差平方和最小，不是「穿過最多點」。
  • 平方會放大離群值的影響 —— 這正是最小平方法對極端值敏感的原因。

10. 先檢查，再預測：使用時的三個提醒

課程最後把「用之前該問的問題」整理成三項檢查，這是實務上最容易被忽略的部分。

10.1 提醒一：相關不等於因果

項目 內容
課程的說明 兩件事一起變動，不表示一件事造成另一件事
課程的舉例 讀書時數之外，基礎能力與讀書方法也可能影響分數

也就是說：直線只描述「一起變動」，背後可能還有第三個因素（或更多）在同時影響兩者。

10.2 提醒二：避免過度外推

項目 內容
課程的說明 外推是拿模型預測資料範圍以外的情況，風險較高
課程的舉例 不能把讀書與分數的直線無限延長，預測分數一直增加

用課程的示意模型 就能看出荒謬之處：

讀書時數 模型預測分數 合理嗎
4 小時 70 分 合理（在觀察範圍內）
20 小時 150 分 不合理 —— 分數上限通常是 100 分
100 小時 550 分 荒謬 —— 直線不會知道現實的上限

重點：直線本身沒有「常識」，把資料範圍外的 丟進去，它照樣給你一個數字。

10.3 提醒三：彎曲關係別硬套

項目 內容
課程的說明 若資料明顯呈現彎曲走勢，一條直線就可能不合適
課程的建議 先看資料的樣子，再決定是否用直線描述

判斷順序應該是：先看資料的形狀 → 再決定用不用直線，而不是先假設直線、再硬套資料。

10.4 三個提醒＝三個自我檢查問題

課程把三項提醒對應成三個問題：

提醒 要問自己的問題
相關不等於因果 能否解釋原因？
避免過度外推 是否超出觀察範圍？
彎曲關係別硬套 關係是否大致筆直？

10.5 考點

  • 課程特別補了一句：在資料範圍內也不代表預測一定可靠 —— 「沒有外推」只是必要條件，不是保證。
  • 三項提醒要能各自配對到正確的問題，這是常見的配對題。

11. 重點回顧：留下四個角色

課程收尾不重講流程，只把四個角色再排一次，並補上一句關於誤差的提醒。

11.1 四個角色總表

11.2 一句話總結

附錄 D：一頁精華（考前 10 分鐘）

【一句話定義】
  線性迴歸 = 用一條直線，描述兩件事的整體關係，並估計可能的結果。

【一行公式，四個角色】            y = a x + b
  x 輸入（自變數）：已知的資料          例：讀書時數
  y 輸出（應變數）：想預測的結果        例：考試分數
  a 斜率：x 加 1，y 變多少              a = Δy / Δx
  b 截距：x = 0 時的起點                x = 0 → y = b

【斜率的長相】
  a > 0 上升 / a = 0 水平（通過 b）/ a < 0 下降 / |a| 越大越陡
  ⚠️ a = 0 → 「這個線性模型」的預測不隨 x 改變，不等於兩者無關

【截距的脾氣】
  改 b → 整條線上下平移，a 不變
  改 a → 整條線換角度
  ⚠️ 資料沒涵蓋 x = 0 時，b 只是數學交點，不是「基本分」

【課程示意模型】 y = 5x + 50   （b = 50, a = 5）
  x = 0,1,2,3,4 → y = 50,55,60,65,70
  讀 4 小時 → 5 × 4 + 50 = 70 分（預測值，不是保證）

【殘差】  殘差 = 實際值 − 預測值 = y − ŷ
  點在線上方 → 正；在線下方 → 負
  目標不是穿過每個點，而是整體差距最小

【最小平方法】 ① 比較差距 → ② 平方後加總 → ③ 找最小總和
  SSE = Σ (y − ŷ)²     平方的作用：防抵消、加重較大誤差
  「最佳」= 殘差平方和最小

【三個提醒】 相關≠因果 / 避免外推 / 彎曲別硬套
  自我檢查：能否解釋原因？超出觀察範圍？關係大致筆直？

【最常考的兩題】
  1. a 和 b 差在哪？ → a 管方向與陡度，b 管起點（x = 0 時的預測）
  2. 預測值與實際值差在哪？ → 預測值來自公式，實際值是觀察到的資料

G-4 實測腳本

以下腳本把課程的每一個數字主張都在本機跑過一次（對應 §7 的示意模型、§8 的殘差、§9 的最小平方法、§5 的截距警告、§10 的外推與彎曲關係）。

"""linear_regression_demo.py -- 線性迴歸入門學習筆記 附錄 G 的本機實測腳本。"""
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

np.set_printoptions(precision=4, suppress=True)

# ① 課程的示意模型 y = 5x + 50（x = 0..4）
a_course, b_course = 5.0, 50.0
x = np.arange(0, 5)
y_course = a_course * x + b_course
for xi, yi in zip(x, y_course):
    print(f"  x={xi}  ->  y = {a_course:.0f}*{xi} + {b_course:.0f} = {yi:.0f}")

# ② a、b 是從資料「學」出來的：讓電腦自己配一次
m0 = LinearRegression().fit(x.reshape(-1, 1), y_course)
print(f"  學到的斜率 a = {m0.coef_[0]:.4f}")
print(f"  學到的截距 b = {m0.intercept_:.4f}")
print(f"  最大還原誤差 = {np.max(np.abs(m0.predict(x.reshape(-1,1)) - y_course)):.2e}")

# ③ 殘差、SSE、MAE、RMSE：三條候選線比一比
actual = np.array([52.0, 54.0, 62.0, 63.0, 71.0])   # 示意用的「實際分數」
for (aa, bb) in [(5.0, 50.0), (4.0, 55.0), (6.0, 45.0)]:
    pred = aa * x + bb
    resid = actual - pred
    sse = float(np.sum(resid ** 2))
    print(f"  y = {aa:.0f}x + {bb:.0f} | 殘差 = {resid} | "
          f"SSE = {sse:7.1f} | MAE = {mean_absolute_error(actual, pred):.4f} | "
          f"RMSE = {np.sqrt(mean_squared_error(actual, pred)):.4f}")

mbest = LinearRegression().fit(x.reshape(-1, 1), actual)
pred_best = mbest.predict(x.reshape(-1, 1))
print(f"    a = {mbest.coef_[0]:.4f}   b = {mbest.intercept_:.4f}")
print(f"    SSE = {np.sum((actual - pred_best)**2):.4f}")
print(f"    R²  = {r2_score(actual, pred_best):.4f}")
print(f"    MAE = {mean_absolute_error(actual, pred_best):.4f}")
print(f"    RMSE = {np.sqrt(mean_squared_error(actual, pred_best)):.4f}")

# ④ 平方的兩個作用：正負抵消 vs 放大誤差
r = np.array([10.0, -10.0])
print(f"  殘差 {r} -> 直接相加 = {r.sum():.1f}；平方後相加 = {np.sum(r**2):.1f}")
r2 = np.array([10.0, 1.0])
print(f"  殘差 {r2} -> 平方和 = {np.sum(r2**2):.1f}；"
      f"殘差 [1. 1.] -> 平方和 = {np.sum(np.array([1.0, 1.0])**2):.1f}")

# ⑤ 過度外推：把 y = 5x + 50 往外丟會發生什麼事
for xi in [4, 10, 20, 100]:
    print(f"  x = {xi:3d} 小時  ->  預測 {a_course*xi+b_course:.0f} 分")

# ⑥ 資料不涵蓋 x = 0 時，截距還能不能解讀成「基本分」
x_sub = np.array([3.0, 4.0, 5.0, 6.0, 7.0, 8.0])
y_sub = 5.0 * x_sub + 50.0 + np.array([-3.0, 2.0, -1.0, 4.0, -2.0, 1.0])
m_sub = LinearRegression().fit(x_sub.reshape(-1, 1), y_sub)
print(f"  只用 x = 3..8 的資料配線：a = {m_sub.coef_[0]:.4f}, b = {m_sub.intercept_:.4f}")
print(f"  真實的 b 是 50.0，估計值差了 {abs(m_sub.intercept_ - 50.0):.4f}")

# ⑦ 彎曲關係硬套直線：R² 會說話
x_curve = np.linspace(-3, 3, 25)
y_curve = x_curve ** 2
m_lin = LinearRegression().fit(x_curve.reshape(-1, 1), y_curve)
r2_lin = r2_score(y_curve, m_lin.predict(x_curve.reshape(-1, 1)))
coef = np.polyfit(x_curve, y_curve, 2)
r2_quad = r2_score(y_curve, np.polyval(coef, x_curve))
print(f"  硬套直線     -> R² = {r2_lin:.4f}")
print(f"  改用二次曲線 -> R² = {r2_quad:.4f}")
