如何執行代碼

位元組碼解碼 Bytecode Interpreter

  • CPython 位元組碼解釋器（又名虛擬器 virtual machine）

  • 在 Python/ceval.c 中，位元組碼解釋器的工作是執行 Python 代碼。

  • 它的主要輸入是一個代碼對象，儘管這不是解釋器的直接參數。

  • 解釋器被結構為一個（遞歸）函數，採用線程狀態（tstate）和堆棧幀（frame）。

- Supports slicing

命名空間是當前定義的符號名稱的集合、以及有關每個名稱引用的物件的資訊。您可以將命名空間視為字典，其中鍵是物件名稱，值是物件本身。每個鍵值對將一個名稱映射到其對應的物件。

四種類型的命名空間 LEGB :

一. 本地：如果在函數內部引用 x，則解釋器首先在該函數的本地最內層範圍內搜索它。
