Object-oriented programming 物件化程式設計

物件化程式設計（OOP）是一種計算機程式設計模型，它圍繞數據或物件而不是函數和邏輯來組織軟體設計。

在 OOP 概念出現之前，過程程式設計概念被用於早期的程式中，它有許多缺點，但被面向物件程式設計方法所克服。

流行的 OOP 語言：Python，C，Java，PHP，JavaScript，.NET ...

Inheritance

When a child class has the same operations and attributes as its parent class, but adds some of its own extras, that's inheritance. Inheritance is a core feature of object oriented programming. 如果超類和子類中都存在相同的方法怎麼辦？

super（）方法

如果我們需要從子類訪問超類方法，我們使用 super（）方法。

Super（）傳回代理物件，該物件將方法調用委託給父類或同級類。這對於訪問已在類中重寫的繼承方法非常有用。

如果我們需要放棄子類覆蓋，我們可以在子類函數前面加上 super（）。

然後 Python 將 定向到超類 display（）。

class Staff:
    name = ""
    def display(self):
    print(f"Registered staff")

class SalesStaff(Staff):
    def display(self):
    super().display()

模組和包是任何大型專案的核心，也是 Python 安裝本身的核心。

模組的分層包 Hierarchical Package of Modules

製作包結構很簡單。只需在檔案系統上按照需要組織代碼，並確保每個目錄都定義一個__init__.py 檔案。

graphics/ init.py primitive/ init.py line.py fill.py text.py formats/ init.py png.py jpg.py

完成此操作后，您應該能夠執行各種導入語句，例如：

import graphics.primitive.line
from graphics.primitive import line
import graphics.formats.jpg as jpg
p.173

init.py 檔的目的是包含可選的初始化代碼，這些代碼在遇到不同級別的包時運行。例如，如果具有語句 import graphics，則將導入檔 graphics/init_.py 並構成 graphics 命名空間的內容。對於匯入，例如匯入

graphics.formats.jpg，檔 graphics/init.py 和 graphics/formats/init.py 都將在最終導入 graphics/format/jpg.py 檔案之前導入。

更多時候，將__init__.py 檔留空是可以的。但是，在某些情況下，它們可能包含代碼。例如，可以使用__init__.py 檔案自動載入子模組，如下所示：

graphics/formats/__init__.py graphics/

__init__.py

from . import jpg primitive/ init.py from . import png line.py fill.py text.py formats/ init.py png.py jpg.py

將模組作為腳本執行 Execute modules as scripts

當您在命令列中運行 Python 模組時

python fibo.py <arguments>

模組中的代碼將被執行，就像您導入它一樣，但 $ \underline{\text{name}} $ 設置為“ $ \underline{\text{main}} $”。這意味著，通過在模組末尾添加以下代碼：

if __name__ == "__main__":
    import sys
fib(int(sys.argv[1]))

您可以使檔既可用作腳本，也可以用作可導入模組，因為解析命令行的代碼僅在模組作為“主”檔執行時運行。

If the module is imported, the code is not run:

>>> import fibo
>>>

這通常用於為模組提供方便的使用者介面，或用於測試目的（將模組作為腳本運行，以執行測試套件）。

生成器 Generator

生成器 允許你聲明一個行為類似於反覆運算器的函數，即它可以在 for 迴圈中使用。生成器的產出就像回傳值一樣。唯一的區別是，yield 不是回傳值，而是將生成器物件回傳給調用方。

生成器提供了一種有效的方式來反覆運算 大型數據集或動態生成值，而無需將整個序列存儲在記憶體中。

Yield 產出：

  • yield

語句用於創建一個生成器函數，該函數可以在執行過程中暫停和恢復，從而允許它隨時間推移生成一系列值。

  • 當生成器函數遇到 yield

語句時，它會暫時暫停其執行，並將指定的值提供給調用方。函數的狀態將被保存，允許它在再次調用時從中斷的位置恢復。

  • 每次調用生成器函數時，它都會從之前生成的點恢復執行，並一直持續到下一個 yield 語句或函數結束。

  • 生成器函數生成的值可以使用 for 循環或通過在產生器物件上顯式調用 next（）函數來反覆運算。

Return 回送：

  • return 語句用於指定函數在調用時應返回的結果或值。

  • 當函數中遇到 return

語句時，它會立即終止函數執行，並將指定的值（如果有）返回給調用方。

  • 執行 return 語句后，函數將完全完成，並且不會執行函數中的任何其他代碼。

斐波那契數列生成器

在數學中，斐波那契數列是一個序列，其中每個數位都是前兩個數字的總和。斐波那契數列中的單個數字稱為斐波那契數。讓我們編寫產生器來生成這些數位。

def genFibonacci(max_num):
    a, b = 0, 1
    count = 0
    while count < max_num:
    yield a
    c = a + b
    a = b
    b = c
    count += 1
fib = list(i for i in genFibonacci(20))

時間序列分析 Time series analysis

時間序列分析是分析在一段時間間隔內收集的一系列數據點的特定方法。在時間序列分析中，分析師在設定的時間段內以一致的時間間隔記錄數據點，而不僅僅是間歇性或隨機地記錄數據點。

時間變數/特徵是自變數，支持目標變數來預測結果。

時間序列分析（TSA）用於基於時間的預測的不同領域，如天氣預報、金融、信號處理、工程領域、控制系統、通信系統。

時間序列是在不同時間戳處收集的數據點序列。這些基本上是在同一時間間隔內從同一數據源收集的連續測量值。此外，我們可以使用這些按時間順序收集的讀數來監測趨勢和隨時間的變化。時間序列模型可以是單變數模型，也可以是多變數模型。

p.190
穩態和非穩態時間序列 Stationary and Non-Stationary Time Series

平穩性是時間序列的一個屬性。穩態序列是指序列值不是時間函數的序列。也就是說，序列的統計屬性（如均值、方差和自相關）隨時間變化是恆定的。

序列的自相關只不過是序列與其先前值的相關性，稍後會詳細介紹。靜止的時間序列也沒有季節性影響。

例：

在特定位置進行的一系列每日溫度測量，其中平均溫度隨時間保持不變。

穩定公司的股價波動性小，沒有長期趨勢。

穩定產品的每日銷售額，隨時間推移保持相對穩定。

在平均潮位保持不變的固定位置記錄的海洋潮汐高度。

非平穩行為可以是趨勢、週期、隨機遊走或三者的組合。數據點通常是非平穩的，或者具有隨時間變化的均值、方差和協方差。

例：

成長型公司的股價隨著時間的推移呈上升趨勢。

季節性產品（如霜淇淋）的月銷售額，具有週期性模式。

隨著個體數量的增加，人口隨時間增長。

受氣候變化影響地區的每日溫度測量值，那裡有明顯的長期溫度上升趨勢。

趨勢

該趨勢顯示了時間序列數據在很長一段時間內的大致方向。趨勢可以是增加（向上）、減少（向下）或水準（靜止）。

p.191
季節性 Seasonality

季節性成分表現出在時間、方向和幅度方面重複的趨勢。一些例子包括由於炎熱的天氣條件導致夏季用水量增加。

週期性成分 Cyclical Component

這些趨勢在特定時間段內沒有固定的重複。週期是指時間序列的起伏、繁榮和貧民窟的時期，主要在商業週期中觀察到。這些周期沒有表現出季節性變化，但通常發生在3到12年的時間段內，具體取決於時間序列的性質。

p.192
不規則變化 Irregular Variation

這些是時間序列數據的波動，當去除趨勢和周期變化時，這些波動變得明顯。這些變化是不可預測的、不穩定的，可能是隨機的，也可能不是隨機的。

ETS分解 ETS Decomposition

ETS 代表 Error-Trend-Seasonality，是用於時間序列分解的模型。ETS 分解用於分離時間序列的不同元件。ETS 一詞代表誤差、趨勢和季節性。

依存 Dependence

它是指同一變數的兩個觀測值在先前時間段的關聯。

差分 Differencing

差分用於使序列平穩並控制自相關。在時間序列分析中，在某些情況下，我們不需要差分，過度差分的序列可能會產生錯誤的估計。

p.193

規範 Specification

它可能涉及使用時間序列模型（如 ARIMA 模型）測試因變數的線性或非線性關係。

ARIMA

代表自回歸綜合移動平均線。如果統計模型基於過去的值預測未來值，則該模型是自回歸的。

模式識別－趨勢 Patterns Recognition – Trend

Autocorrelation and Partial Autocorrelation

Autocorrelation是時間序列中不同點的兩個觀測值之間的相關性。例如，由區間分隔的值可能具有很強的正相關或負相關。當存在這些相關性時，它們表明過去的值會影響當前值。

可預測性 Forecastability

時間序列的規律性和可重複性越強，就越容易預測。
