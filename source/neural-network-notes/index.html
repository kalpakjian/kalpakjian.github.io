2. Neural Network：AI 基本原則與生物神經元（PDF p2–p3）

原稿 p2、p3 的標題都是「Neural Network — AI Basic Principles: Artificial Neural Network」， 但內容其實是先講生物神經元，再用它當作人工神經網路的靈感來源。

2.1 生物神經元的構造（p2）

構造 英文 說明（原稿敘述）
細胞體 cell body / soma 內含細胞核（cell nucleus）
樹突 dendrites 由細胞體分岔出去的纖維，負責接收訊號
軸突 axon 一條較長的纖維，負責送出訊號
突觸 synapses 神經元之間的接點；一個神經元可與 10 到 100,000 個其他神經元連接
訊號傳遞 — 訊號透過複雜的電化學反應（electrochemical reaction）在神經元之間傳播

2.2 動作電位：全有全無（p3）

  • 傳遞訊號時，神經元會產生一種全有全無（all-or-nothing）的電化學脈衝，稱為 動作電位（action potential）。
  • 一旦細胞達到某個閾值（threshold），動作電位就會發火（fire），把訊號沿著軸突送出。
  • 動作電位只有發生與不發生兩種，沒有「部分發火」這種事。
  • 這些訊號在短期控制腦的活動，也促成神經元連結的長期改變。
  • 原稿的結論：這些機制被認為是腦中學習的基礎。

考點（超常考）： 1. 哪個構造負責接收？→ 樹突（dendrites）。 2. 哪個構造負責送出？→ 軸突（axon）。 3. 神經元之間在哪裡連接？→ 突觸（synapses）。 4. 動作電位的特性？→ 全有全無，達閾值才發火，沒有部分發火。 5. 「學習」在生物層面指的是什麼？→ 神經元連結的長期改變。

2.3 為什麼要先講生物神經元

人工神經網路的每一個零件，都能對應到生物神經元的一個部位—— 這也是「Artificial Neural Network」這個名字的由來：借結構、不借化學。 下一節（p4）就會把這個對應關係寫成「神經元」與「權重」兩個名詞。

3. Neural Network：神經網路的組成（PDF p4）

原稿 p4 用兩條列點定義神經網路由什麼組成：

組成 原稿說明 白話
Neurons 神經元 Neurons which pass input values through functions and output the result 神經元把輸入值通過函數，再輸出結果
Weights 權重 Weights which carry values between neurons 權重負責在神經元之間傳遞數值

3.1 一個神經元到底算了什麼

把上圖拆成兩個步驟，這是最重要的心智模型：

步驟 數學式 意義
① 加權總和 a = Σᵢ wᵢxᵢ + b 把每個輸入乘上它的權重後相加，再加上偏置 b
② 激勵函數 y = f(a) 把加權總和交給 f，決定這個神經元要輸出什麼
  • 權重 w 是「可學習」的參數：訓練的過程就是在調整這些 w（以及 b）。
  • b 是 bias（偏置）：可以想成「可調整的門檻」，讓神經元不一定要在輸入全為 0 時才輸出 0。
  • 若沒有步驟 ②（或 ② 是線性的），多層網路在數學上等價於一層線性轉換—— 這正是「激勵函數必須是非線性」的理由（第 7 節會再展開）。

考點：原稿把「神經元」定義成「把輸入值通過函數後輸出」，把「權重」定義成 「在神經元之間傳遞的數值」。考試常考這兩個定義的配對，別把權重說成「儲存資料的地方」。

4. Artificial Neural Network：三層結構與傳播方向（PDF p5）

原稿 p5 只有五個詞（其餘都是圖）：Input Layer、Hidden Layer、Output Layer、Feed-forward、Back Propagation。

4.1 三層結構

層 英文 角色
輸入層 Input Layer 接收原始特徵（例如一張圖的像素值）
隱藏層 Hidden Layer 做特徵轉換；可以有好多層，層數越多網路越「深」
輸出層 Output Layer 產生最後的答案（類別機率或數值）

4.2 兩個傳播方向（一定要分清楚）

名稱 方向 做什麼
Feed-forward 前向傳播 輸入 → 輸出 把資料往前算，得到預測值
Back Propagation 反向傳播 輸出 → 輸入 用「預測與答案的誤差」回頭調整每一層的權重

一個完整的訓練循環是：前向傳播算答案 → 算誤差 → 反向傳播改權重 → 再前向傳播， 反覆很多次（每一輪叫一個 epoch）。

考點： - 「用誤差來更新權重」的是 Back Propagation（反向傳播），不是 Feed-forward。 - 前向傳播的方向是 輸入層 → 隱藏層 → 輸出層。 - 隱藏層的數量決定網路「深不深」；輸入層與輸出層的數量則由問題決定 （例如 3 類別分類 → 輸出層 3 個神經元）。

5. Artificial Neural Network：ANN 與 DNN 的定義（PDF p6）

原稿 p6 給出兩個正式定義，這一頁是必背：

5.1 ANN（Artificial Neural Network，人工神經網路）

An Artificial Neural Network is a computational model inspired by the structure and functioning of biological neural networks. It consists of interconnected nodes (artificial neurons) organized into layers, and it can learn from data to make predictions or decisions.

中文重點：

  • 是一種計算模型，靈感來自生物神經網路的結構與運作方式。
  • 由互相連接的節點（人工神經元）組成，並且分層排列。
  • 能從資料中學習，用來做預測或決策。

5.2 DNN（Deep Neural Network，深度神經網路）

A Deep Neural Network is a type of neural network that has multiple hidden layers, allowing it to learn complex patterns and representations from input data. It is called "deep" because of its depth, with more than two hidden layers. Deep neural networks have been successful in various domains, such as computer vision and natural language processing.

中文重點：

  • 是神經網路的一種（DNN 屬於 ANN）。
  • 具備多個隱藏層，能學到複雜的模式與表徵。
  • 「deep」指的是深度：隱藏層超過兩層（more than two hidden layers）。
  • 已成功應用於電腦視覺與自然語言處理（NLP）等領域。

5.3 兩者比較

比較項 ANN DNN
隱藏層數 少（1～2 層） > 2 層
別名 淺層網路（shallow） 深度網路（deep）
能力 學簡單的關係 學複雜的模式與表徵
典型應用 表格資料、簡單分類 影像辨識、語音、NLP

考點（必考）： 1. 「deep」的判斷標準 → 隱藏層多於兩層（不是「資料很多」、也不是「神經元很多」）。 2. DNN 成功應用的兩個代表領域 → computer vision 與 natural language processing。 3. ANN 的定義關鍵字 → inspired by biological neural networks、organized into layers、 learn from data to make predictions or decisions。

拓撲指的是網路的「形狀」——也就是：

拓撲要素 說明

  • 淺層網路：只能學到比較簡單的關係（例如用幾個特徵畫一條分界線）。
  • 深層網路：逐層堆疊出階層式的表徵——以影像為例，前面的層學到邊緣與顏色， 中間的層組合成紋理與局部形狀，後面的層才認得出「貓」或「車」。
  • 這也是為什麼 CNN（卷積神經網路）幾乎都是 deep 的架構。

考點： - 「相對淺、簡單任務」→ ANN；「深、複雜模式辨識」→ DNN。 - Network Topology 談的是網路的結構（層數、寬度、連接方式），不是資料的形狀。

7. Activation Function：激勵函數是什麼（PDF p8）

原稿 p8 用一段話定義激勵函數（原文照錄）：

中文拆解：

原稿說法 意義
a math rule used in a neural network 它是一條數學規則
sits inside a neuron 它位於神經元內部（不是在外面）
takes the total input numbers, adds them up 把輸入的數字加總起來

7.1 激勵函數的四大作用

作用 說明
① 決定輸出 把加權總和 a 轉成這個神經元實際的輸出 y
② 引入非線性 最重要：沒有它，多層網路等價於一層線性模型
③ 控制輸出範圍 例如 Sigmoid 壓到 (0,1)、ReLU 壓到 [0, ∞)
④ 影響訓練 可不可微、梯度會不會消失，直接決定網路能不能訓練得動

7.2 本節會學到的四種激勵函數（先看總表）

激勵函數 公式 輸出範圍 用在哪裡 備註
TLU（階梯） y = 1 if a ≥ θ else 0 {0, 1} 早期感知機 不可微，解不了 XOR
ReLU f(a) = max(0, a) [0, ∞) 隱藏層（預設） 快、正區間梯度固定 1
Sigmoid σ(a) = 1/(1+e⁻ᵃ) (0, 1) 二元分類的輸出層 兩端飽和 → 梯度消失
Softmax pᵢ = e^zᵢ / Σⱼ e^zⱼ (0, 1) 且總和 1 多類別分類的輸出層 輸出可視為機率分布

考點： - 激勵函數位於神經元內部，處理的是「加權總和之後」的值。 - 它存在的關鍵理由是引入非線性（non-linearity），讓網路能學 hard patterns。 - 若把激勵函數拿掉，整個深層網路會退化成線性模型。

8. Threshold Logic Unit（TLU）（PDF p9–p10）

原稿 p9 是結構圖、p10 是圖形，兩頁合起來才完整。

8.1 TLU 的結構（p9）

p9 的圖上標示了四個部位：inputs（輸入）、weights（權重）、activation（激勵）、output（輸出）， 並寫出兩條式子：

a = Σ(i=1..n) wᵢ xᵢ
y = 1 if a ≥ θ
    0 if a < θ
符號 意義
x₁ … xₙ n 個輸入（特徵）
w₁ … wₙ 對應的權重
a 加權總和（有些教材寫成 net 或 z）
θ（theta） threshold 閾值
y 輸出，只有 0 或 1 兩種

8.2 TLU 的激勵函數圖形（p10）

原稿 p10 只畫了 y 對 a 的圖（一個階梯：a 未達 θ 時 y = 0，達到 θ 時跳到 1）。

8.3 TLU 的歷史與限制

  • TLU 是最早能「學習」的神經元模型：McCulloch–Pitts 神經元（1943）提出雛形， Rosenblatt 的感知機（Perceptron, 1958）把它變成可訓練的演算法。
  • 限制一：不可微。階梯函數在 θ 處不連續，梯度不是 0 就是不存在， 因此無法直接使用梯度下降。
  • 限制二：只能解線性可分的問題。TLU 畫出的是一條直線決策邊界： 能解 AND、OR，但解不了 XOR（這是 1969 年 Minsky 與 Papert 指出的著名瓶頸）。

考點： 1. TLU 的輸出只有 0 與 1（非黑即白），不是機率。 2. TLU 的兩個致命傷：不可微、只能線性分割（解不了 XOR）。 3. 也因為這兩個限制，才有後面的 Sigmoid（可微）與多層網路（非線性）的發展。

9. Rectified Linear Units（ReLU）（PDF p11–p12）

原稿 p11 是結構圖、p12 是圖形。

9.1 ReLU 的結構（p11）

p11 的圖與 TLU 幾乎一樣（inputs → weights → activation → output），但式子換成：

a = Σ(i=1..n) wᵢ xᵢ
y = a = Σ(i=1..n) wᵢ xᵢ

原稿把 y 直接寫成 a（也就是正值原樣通過）。標準寫法就是：

f(a) = max(0, a)
情況 輸出 說明
a ≥ 0 y = a 原樣通過（斜率 1）
a < 0 y = 0 直接壓成 0（「整流」）

9.2 ReLU 的圖形（p12）

原稿 p12 畫了兩張圖對照：一張是線性（一條斜直線），一張是 ReLU（0 的左半壓平、右半斜上去）。

9.3 為什麼 ReLU 成為主流

優點 說明
計算極快 只做一次比較（max），不像 Sigmoid 要算指數
不會梯度消失（正區間） 正區間的導數固定是 1，誤差可以穩定往回傳
稀疏性 負值輸出 0，讓網路只啟動部分神經元，效率更好
缺點 說明
Dead neuron（神經元死亡） 若某神經元的加權總和長期為負，梯度永遠是 0，它就再也不會被更新
輸出無上界 輸出可以是任意大的正數（不像 Sigmoid 有界）

考點： 1. ReLU 的公式是 max(0, a)；負值歸零、正值原樣通過。 2. ReLU 的導數在正區間是 1（不是 0），所以不會梯度消失。 3. 「Dead neuron」是 ReLU 的典型問題，原因就是負區間梯度為 0。

10.1 Sigmoid 的結構（p13）

p13 的圖上標示：inputs / weights / activation / output，並寫出兩條式子：

a = Σ(i=0 (or 1) .. n) wᵢ xᵢ
y = σ(a) = 1 / (1 + e⁻ᵃ)

（i = 0 (or 1) 指的是：偏置項有時從 0 開始編號，有時從 1 開始，兩種寫法都有人用。）

10.2 Sigmoid 的圖形（p14）

原稿 p14 同時放了 Sigmoid 與 Softmax 兩張圖（頁面上標題就是這兩行）。

10.3 Sigmoid 的特性與用途

特性 說明
輸出範圍 (0, 1)——永遠不會是 0 或 1，但可以無限接近
σ(0) = 0.5 輸入 0 時輸出正好一半，常被當成決策門檻
可微 處處平滑可微分，所以可以用梯度下降訓練
導數形式漂亮 σ'(a) = σ(a)·(1 − σ(a))，好算
兩端飽和 輸入很大或很小時，導數趨近 0 → 梯度消失（vanishing gradient）

常見用途：

  • 二元分類的輸出層：輸出值可直接解讀為「是」的機率（> 0.5 判為正類）。
  • 早期網路的隱藏層，或需要輸出被限制在 (0, 1) 的場合（例如閘門、注意力權重）。
  • 不適合當深層網路的隱藏層：兩端飽和會讓梯度消失，訓練不動 → 改用 ReLU。

考點： 1. Sigmoid 的值域是 (0, 1)，σ(0) = 0.5。 2. 它的主要缺點是梯度消失（兩端飽和），不是「輸出不是機率」。 3. 二元分類的輸出層用 Sigmoid；多類別用 Softmax。

11.1 Softmax 的結構（p15）

p15 的圖把「一組輸入」通過 activation 後，得到一組輸出（不是單一個 y）， 代表它處理的是多類別的輸出層。

pᵢ = e^zᵢ / Σⱼ e^zⱼ        （i = 1 … K，K 是類別數）

11.2 Softmax 的圖形（p16）

原稿 p16 畫的是 y 對 a 的曲線——就是指數函數的形狀（Softmax 的分子 e^z 決定了它的行為）。

11.3 Softmax 為什麼長這樣

設計 原因
分子取 指數 e^z ① 保證所有輸出為正；② 把差距指數放大，讓大的更大、模型更「有自信」
除以總和 讓所有輸出加總為 1，成為合法的機率分布
取 argmax 機率最大的那一類就是預測結果（注意：訓練時用機率，預測時通常只取最大）
平移不變性 softmax(z) = softmax(z − c)；實作時常先減去最大值以避免指數溢位

計算範例（以 z = [2.0, 1.0, 0.1] 為例）：

步驟 數值
logits z 2.0 / 1.0 / 0.1
e^z 7.389 / 2.718 / 1.105（總和 11.213）
除以總和 0.659 / 0.242 / 0.099（總和 1.000）
預測 第 1 類（機率最高 0.659）

比較 Sigmoid Softmax
適用 二元分類 多類別分類
輸出個數 1 個（其餘類別機率 = 1 − p） K 個（每個類別一個）
輸出總和 不固定 一定等於 1
公式 1/(1+e⁻ᵃ) e^zᵢ / Σⱼe^zⱼ
關係 Softmax 在 K = 2 時，會退化為 Sigmoid 的形式 —

考點： 1. Softmax 的輸出加總為 1，這是它與 Sigmoid 最大的差別。 2. 多類別互斥（只能選一個）→ Softmax；多標籤（可同時成立）→ 每個標籤各一個 Sigmoid。 3. 實作上為避免 exp 溢位，會先減去 logits 的最大值（不影響結果）。

  • 輸出的是連續數值（房價、溫度、銷售量），不是類別。

  2. 步驟 6 的 train/validate 與步驟 7 的 test 是兩件事： 驗證集用來調參數，測試集只能用一次，用來報告最終表現。
  3. 步驟 9、10 是「維運」：模型上線後會漂移（drift），所以必須決定多久跑一次、 多久重訓一次——這是很多專案失敗的地方。

考點（必背順序）： 定義問題 → 定目標變數與指標 → 取資料 → 清理合併 → 選演算法 → 訓練驗證 → 測試 → 部署 → 執行頻率 → 更新頻率。 特別注意「驗證」和「測試」是分開的兩個步驟，且最後兩步與「頻率」有關。

19.1 分類實例：混淆矩陣（p25）

原稿的 2×2 表格數字是：TP = 126、FP = 21、FN = 7、TN = 119（總共 273 筆）。

縮寫 全名 中文 意義
TP True Positive 真陽性 實際是正類，模型也說是正類 → 猜對
FP False Positive 偽陽性 實際是負類，模型卻說是正類 → 誤報

由這四格算出的五個指標（本筆記已用 Python 逐一驗算）：

指標 公式 代入 結果
Accuracy 準確率 (TP+TN) / 全部 (126+119) / 273 89.74%

口訣：

  • Precision 看「預測為正的裡面有多少是真的」（分母是預測的橫列／直行）→ 別誤報。

  • Accuracy 只看總體對的比例，因此在類別極不平衡時會騙人 （例如 99% 都是負類，全猜負類也有 99% 準確率，但 Recall = 0）。

19.2 門檻（threshold）的取捨

上圖下半部說明：模型輸出的是機率，要自己選一個門檻（例如 0.5）才變成類別。

把門檻調高 把門檻調低
更少被判為正類 → FP 減少、FN 增加 更多被判為正類 → FN 減少、FP 增加
Precision 上升、Recall 下降 Recall 上升、Precision 下降

所以選門檻要看任務代價：

  • 寧可誤報、不可漏抓（癌症篩檢、詐欺偵測、瑕疵檢測）→ 門檻調低，追求高 Recall。
  • 誤報代價很高（把正常信件丟進垃圾桶、把正常客戶擋掉）→ 門檻調高，追求高 Precision。

21. Clustering：分群的兩個距離目標（PDF p29）

原稿 p29 沒有任何句子，只有四段重複的標註文字：

Intracluster distances are minimized
Intercluster distances are maximized

21.1 兩句話的真正意思

名詞 中文 目標
Intracluster distance 群內距離 最小化（minimized）——同一群的點越靠近越好
Intercluster distance 群間距離 最大化（maximized）——不同群的中心越遠越好

一句話：「同群要緊、異群要遠」。

21.2 k-means 怎麼做到這件事

k-means 是最常見的分群演算法，步驟是：

  1. 決定 k（要分幾群），隨機挑 k 個中心點（centroid）。
  2. 指派：把每個資料點分給最近的中心。
  3. 更新：把每個群的中心重算成該群所有點的平均。
  4. 重複 2–3 直到中心不再移動（或達到最大迭代次數）。

它真正在最小化的目標函數叫 inertia（群內距離平方和）：

inertia = Σ (每個點到它所屬群中心的距離²)

inertia 越小，代表同一群越緊密——這就是「intracluster distances are minimized」。

21.3 使用 k-means 的三個實務注意事項

注意事項 說明
k 要自己決定 常用 elbow method（手肘法）：把 k 從 1 往上畫 inertia，找曲線轉折（手肘）的位置
對尺度敏感 特徵單位差很多時（例如公分 vs 元），必須先標準化
對離群值敏感 因為中心是「平均值」，一個極端值會把中心拉走；形狀假設是球形且大小相近

考點： 1. 背下這兩句：intracluster distances are minimized / intercluster distances are maximized。 2. k-means 的目標函數是 inertia（群內距離平方和）。 3. k-means 屬於非監督式學習，而且k 需要人先指定。

B.1 十大陷阱總表

附錄 E：一頁精華（考前 10 分鐘）

========== 1. 生物 → 人工 ==========
樹突（收）→ 細胞體（加總）→ 過閾值才發火（全有全無、沒有部分發火）→ 軸突（送）→ 突觸
對應到人工：輸入 x → a = Σwᵢxᵢ + b → f(a) → y
神經網路的兩個零件：Neurons（把輸入通過函數後輸出）、Weights（神經元之間傳遞的數值）

========== 2. 網路結構 ==========
Input Layer → Hidden Layer（可多層）→ Output Layer
Feed-forward：輸入往輸出算答案
Back Propagation：誤差由輸出往輸入回傳，用來更新權重
ANN：淺、簡單任務        DNN：> 2 個隱藏層、複雜模式辨識（CV / NLP）
Network Topology = 網路的形狀（層數、寬度、連接方式）

========== 3. 激勵函數 ==========
定義：神經元內部的數學規則；把輸入加總後決定要不要送出；加入「非線性」讓網路能學難的模式
TLU     y = 1 if a ≥ θ else 0   輸出 {0,1}，不可微，解不了 XOR
ReLU    f(a) = max(0, a)        隱藏層預設；正區間梯度 1；負區間 0（dead neuron）
Sigmoid σ(a) = 1/(1+e⁻ᵃ)        輸出 (0,1)，σ(0)=0.5；兩端飽和 → 梯度消失
Softmax pᵢ = e^zᵢ/Σⱼe^zⱼ        輸出總和 = 1，多類別分類
範例：z=[2.0,1.0,0.1] → e^z=[7.389,2.718,1.105]（總和 11.213）→ p=[0.659,0.242,0.099]

========== 4. 問題 → 激勵函數 ==========
Classification ─┬─ Binary      → 1 個輸出 + Sigmoid
                 ├─ Multiclass  → K 個輸出 + Softmax（互斥）
                 └─ Multilabel  → 每個標籤一個 Sigmoid
Regression → ReLU / 線性（輸出連續數值；用 MAE / MSE / R² 評估）

========== 5. 機器學習 ==========
十步：定義問題 → 定目標變數與指標 → 取資料 → 清理合併 → 選演算法
      → 訓練並驗證 → 測試 → 部署 → 決定執行頻率 → 決定更新頻率
三條軸：Human Supervision?（監督 / 非監督 / 強化）
        Learn Incrementally?（批次 / 增量）
        How they generalize?（基於實例 / 基於模型）
AI ⊃ Machine Learning ⊃ Deep Learning（大數據是原料、資料科學是方法）

========== 6. 監督式 vs 非監督式 ==========
監督式：{(x₁,y₁)…(xₙ,yₙ)} 有標籤 → Classification（SVM / NN / 決策樹 / k-NN）
                                               Regression（線性迴歸 / NN）
非監督式：{x₁…xₙ} 沒標籤 → Clustering；可以是目的本身，也可以是前處理

========== 7. 混淆矩陣（p25 的數字）==========
TP=126  FP=21  FN=7  TN=119（總 273）
Accuracy  = (126+119)/273 = 89.74%
Precision = 126/(126+21)  = 85.71%   ← 分母是「預測為正」
Recall    = 126/(126+7)   = 94.74%   ← 分母是「實際為正」
F1 = 2PR/(P+R) = 0.900      Specificity = 119/140 = 85.00%
門檻 ↓ → Recall ↑ / FP ↑；門檻 ↑ → Precision ↑ / FN ↑

========== 8. 迴歸（p26 的模型）==========
f(x) = 35 + 1.5x  →  x=54→116、62→128、68→137、74→146、80→155

========== 9. 分群 ==========
intracluster distances are MINIMIZED（同群要緊）
intercluster distances are MAXIMIZED（異群要遠）
k-means：挑 k 個中心 → 指派最近的點 → 重算中心 → 迭代；最小化 inertia
k 要人決定（elbow method）；對尺度與離群值敏感
