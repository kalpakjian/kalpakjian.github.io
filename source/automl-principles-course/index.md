## 1 · AutoML 十課（自編・原理為主體）

![AutoML 十課 學習筆記](/img/covers/automl-principles-notes.png)

- **涵蓋**：**10 課 × 約 3 小時**，主體講**原理**，實作只用來**證明原理**
- **三條主線一路展開**：
  - **問題線**：迴歸與誤差的本質（殘差 → MAE／RMSE／MAPE／R²）→ 分類與評估的本質（混淆矩陣 → 門檻 vs AUC）
  - **資料線**：切分方式＝你對未來的假設 → 三種洩漏（目標／時間／前處理）→ 特徵工程的時間軸準則
  - **自動化線**：搜尋成本公式 → 回報遞減與 CV 選擇偏誤 → 遺傳規劃搜尋「管線樹」→ 集成與兩條哲學路線
- **每一課都有可跑的示範**（本機執行，只依賴 numpy + scikit-learn 或 TPOT），
  而且**所有示範都實跑過**，關鍵數字直接寫進內文：
  - 迴歸：誤差放大 20 倍 → RMSE 放大 **8.99 倍**、MAE 只放大 **4.80 倍**
  - 分類：正類 4.5% 時，「什麼都不做」的 Accuracy 就有 **0.9545**，模型 Recall 只有 **0.1209**
  - 洩漏：**純雜訊**的資料，用全部資料挑特徵也能做出 **R² = 0.2977**
  - 搜尋：CV 選擇偏誤的樂觀差距從 **+0.0233 → +0.0900 → +0.1111**
  - 集成：單一深樹標準差 **0.0265** → Bagging **0.0090** → Boosting **0.0012**
  - 漂移：PSI **0.0071**（穩定）／**0.5985**（明顯漂移）；⚠️ 小樣本會失真
- **雲端只講概念、不教介面**（第 8 課）：五大概念一次對應回本機等價物，
  並用一組真實課程數字講成本（訓練不到 40 分鐘 vs 端點每月常駐）
- **附錄獨立、標明保鮮期**：環境建置、**實作問題記錄簿（15 筆實測踩坑）**、
  版本變更對照、指令速查、實測數據表——主體完全不寫會過期的東西
