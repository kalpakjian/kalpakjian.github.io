一、輸出尺寸與感受野

O          = floor((N + 2P − F) / S) + 1
參數        = (F × F × C_in × C_out) + C_out
乘加次數    = H_out × W_out × C_out × F × F × C_in
感受野      r_out = r_in + (k − 1) · j_in ,  j_out = j_in · S
輸入設定輸出備註
7×7K3 P0 S15×5deck 6 的 p31 例子
7×7K3 P1 S17×7這就是 same（K 奇數、S=1）
7×7K3 P0 S23×3剩 1 欄 1 列沒用到
7×7K3 P0 S32×249 格只剩 4 格
7×7K5 P0 S31×1輸出 1×1 時 squeeze() 會變純量（Lab 1 的原始碼就在此崩潰）
28×28K3 P0 S213×13是 13 不是 14（floor）
28×28K3 P0 S126×26CNN 2 deck 模型的第一層

P = 0 是 valid；P = (F − 1)/2 是 same，而且只有 S = 1 時才保證尺寸不變； K 為偶數時 TF 把多出的一圈補在右下（不對稱），所以 CNN 幾乎只用奇數核。

LeNet-5 的感受野：5 → 6 → 14 → 16 → 32（C5 剛好看見整張 32×32）。

口徑說明（兩份筆記以前各寫一個數字，就是差在這裡）：

  • 「全連接」指 Dense 類層；LeNet 的 C5 是卷積，只是輸出 1×1 常被畫成 FC。
  • 百分比的分母都是該模型的總參數；引用時請連括號裡的範圍一起寫。

卷積 vs 全連接的差距（deck 6 的例子）：1024 → 120 全連接要 123,000 個權重， 換成 5×5 卷積只要 25 個 → 差 4,920 倍。

名稱核判準

一句話：權重和 = 1 保留亮度；權重和 = 0 只留變化。符號也有意義（正＝由暗到亮）。

五、常見陷阱總表（兩課合併）

#陷阱錯誤寫法正確寫法
1攤平影像餵全連接把影像拉成一個長向量用卷積保留空間結構，末端才攤平
2忘了參數共享每個位置一組權重一個核一套權重滑過全圖
3把卷積寫成「翻轉」「反向要翻核」實作是互相關；只有 ∂E/∂X 要 rot180
4銳化核心寫成 30 −1 0 / −1 3 −1 / 0 −1 0中心是 5，總和才是 1
5邊緣核心總和不是 0中心 −3中心 −4
6輸出尺寸公式記錯O = (N − F)/S + 1O = (N + 2P − F)/S + 1
7忽略通道數「一個核＝一張特徵圖」C_out 個核、參數要乘 C_in
8以為池化有權重給池化算 trainable params池化沒有可學參數（count_params() == 0）
9ReLU 只放在最後輸出前放一次每一層卷積之後都要
10以為 LeNet 用 ReLU + max pool「LeNet-5 = ReLU + max pooling」它是 Sigmoid/Tanh + 平均池化
11把平移等變說成不變「參數共享 → 平移不變」卷積是等變；不變要靠池化
12以為卷積就是翻轉核反向要 rot180(F)深度學習的卷積＝互相關
13感受野只算核大小「感受野 = F」r_out = r_in + (k−1)·j_in，要連跳距一起遞推
14depth 由輸入通道決定「輸入 3 通道 → depth 3」depth = 濾波器數量；輸入通道只影響每個核的深度
15ReLU 一半是 0 就是死了「50% 零激活 = 死亡」那是稀疏；死亡是「對所有輸入都輸出 0」

症狀 → 原因：特徵圖比預期大 → 忘了 +2P；比預期小 → stride 記錯； 參數對不上 → 忘了乘 C_in 或忘了 bias；邊界被削一圈 → P=0； loss 降不下來 → 卷積後沒 ReLU（整個網路變線性）；訓練好但驗證差 → 參數太多、沒有共享。

六、一頁精華（考前 10 分鐘）

【主線】影像（矩陣）→ 卷積（局部＋共享）→ 特徵圖（通道↑ 空間↓）
        → 層層堆疊（邊緣→部件→物件）→ 全連接 → softmax → 類別機率

【三個關鍵字】局部性（只看一小塊）／共享（同一組權重滑全圖）／階層（越深越抽象）

【四個數字】O = (N+2P−F)/S + 1 ；參數 = F²·C_in·C_out + C_out
           乘加 = H_out·W_out·C_out·F²·C_in ；r_out = r_in + (k−1)·j_in

【池化】無參數、降維、空間不變，代價是放棄精確位置
【ReLU】max(0, x)；死亡 = 梯度恆 0、權重永不再更新
【參數量】LeNet 61,706（C5 佔 78%）；deck 模型 1,668,490（Dense(1024) 98.2%）
【FCN】用 Conv2DTranspose 上採樣，才能輸出跟輸入同尺寸的標籤圖
【平移】卷積＝等變；池化＝不變（兩者不是同一件事）
