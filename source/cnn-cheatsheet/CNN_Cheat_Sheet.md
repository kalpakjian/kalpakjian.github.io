## 一、輸出尺寸與感受野

```text
O          = floor((N + 2P − F) / S) + 1
參數        = (F × F × C_in × C_out) + C_out
乘加次數    = H_out × W_out × C_out × F × F × C_in
感受野      r_out = r_in + (k − 1) · j_in ,  j_out = j_in · S
```

| 輸入 | 設定 | 輸出 | 備註 |
|---|---|---|---|
| 7×7 | K3 P0 S1 | 5×5 | deck 6 的 p31 例子 |
| 7×7 | K3 P1 S1 | 7×7 | 這就是 same（K 奇數、S=1） |
| 7×7 | K3 P0 S2 | 3×3 | 剩 1 欄 1 列沒用到 |
| 7×7 | K3 P0 S3 | 2×2 | 49 格只剩 4 格 |
| 7×7 | K5 P0 S3 | 1×1 | 輸出 1×1 時 `squeeze()` 會變純量（Lab 1 的原始碼就在此崩潰） |
| 28×28 | K3 P0 S2 | 13×13 | 是 13 不是 14（floor） |
| 28×28 | K3 P0 S1 | 26×26 | CNN 2 deck 模型的第一層 |

`P = 0` 是 valid；`P = (F − 1)/2` 是 same，而且**只有 S = 1 時才保證尺寸不變**；
K 為偶數時 TF 把多出的一圈補在右下（不對稱），所以 CNN 幾乎只用奇數核。

LeNet-5 的感受野：5 → 6 → 14 → 16 → 32（C5 剛好看見整張 32×32）。

## 二、參數速算（三個模型對照）

| 模型 | 總參數 | 真卷積 | 全連接 | 重點 |
|---|---|---|---|---|
| LeNet-5 | **61,706**（不含池化）／61,750（含可訓練平均池化） | 2,572（4.2%） | 11,014（17.8%） | C5 佔 **78.0%**：它是 5×5 卷積但輸出 1×1，等效 FC |
| CNN 2 deck 模型 | 1,668,490 | 18,816（1.1%） | 1,649,674 | **Dense(1024) 單層 98.2%**；連 Dense(10) 一起算才是 98.9% |
| Lab 2 小模型 | 693,962 | 320（0.05%） | 693,642（99.95%） | 卷積幾乎免費，貴的永遠是攤平後那層 |

**口徑說明**（兩份筆記以前各寫一個數字，就是差在這裡）：

- 「全連接」指 Dense 類層；LeNet 的 C5 是**卷積**，只是輸出 1×1 常被畫成 FC。
- 百分比的分母都是該模型的總參數；引用時請連括號裡的範圍一起寫。

**卷積 vs 全連接的差距**（deck 6 的例子）：1024 → 120 全連接要 123,000 個權重，
換成 5×5 卷積只要 25 個 → 差 **4,920 倍**。

## 三、經典核心速查

| 名稱 | 核 | 判準 |
|---|---|---|
| 平均（模糊） | `1/9 × ones(3,3)` | 權重和 = 1 → 不改亮度 |
| 銳化 | `0 −1 0 / −1 5 −1 / 0 −1 0` | 權重和 = 1（中間是 5，不是 3） |
| 邊緣（Laplacian） | `0 1 0 / 1 −4 1 / 0 1 0` | 權重和 = 0 → 只留變化（中心 −4，不是 −3） |
| 邊緣（deck p26） | `1 0 −1 / 1 0 −1 / 1 0 −1` | 左右相減 → 偵測垂直邊 |
| Sobel x | `−1 0 1 / −2 0 2 / −1 0 1` | Lab 1.4 拿它比 NumPy／PyTorch／Keras |

**一句話**：權重和 = 1 保留亮度；權重和 = 0 只留變化。符號也有意義（正＝由暗到亮）。

## 四、術語對照

| English | 繁中 | 一句話 |
|---|---|---|
| convolution | 卷積 | 濾波器滑過輸入，逐點相乘再相加 |
| cross-correlation | 互相關 | 卷積**不翻核**的版本；PyTorch／TF／OpenCV 實作的都是這個 |
| kernel / filter | 卷積核／濾波器 | 可學習的權重小矩陣（同義） |
| feature map | 特徵圖 | 一個濾波器的輸出；張數 = filters |
| channel | 通道 | `C_out` 個濾波器 → `C_out` 個通道 |
| stride | 步幅 | 每次移動幾格；只會讓輸出變小 |
| padding（SAME／VALID） | 填補 | SAME 保持尺寸、VALID 不補 |
| receptive field | 感受野 | 節點在輸入上看到的區域 |
| parameter sharing | 參數共享 | 同一個核掃全圖，參數量與影像大小無關 |
| pooling | 池化 | 鄰域取最大／平均，**沒有可學參數** |
| dilation | 空洞率 | 元素之間插間隔，放大感受野不增參數 |
| de novo feature learning | 從零學特徵 | 特徵是訓練出來的，不是人工設計 |
| fully connected | 全連接 | 每個輸入連到每個輸出；參數通常堆在這裡 |
| softmax | — | 把分數轉成機率，加總為 1 |
| backpropagation | 反向傳播 | 鏈鎖律回傳梯度；卷積層的梯度還是卷積 |
| dying ReLU | ReLU 死亡 | 單元恆輸出 0、梯度恆 0 |

## 五、常見陷阱總表（兩課合併）

| # | 陷阱 | 錯誤寫法 | 正確寫法 |
|---|---|---|---|
| 1 | 攤平影像餵全連接 | 把影像拉成一個長向量 | 用卷積保留空間結構，末端才攤平 |
| 2 | 忘了參數共享 | 每個位置一組權重 | 一個核一套權重滑過全圖 |
| 3 | 把卷積寫成「翻轉」 | 「反向要翻核」 | 實作是互相關；只有 `∂E/∂X` 要 `rot180` |
| 4 | 銳化核心寫成 3 | `0 −1 0 / −1 3 −1 / 0 −1 0` | 中心是 **5**，總和才是 1 |
| 5 | 邊緣核心總和不是 0 | 中心 `−3` | 中心 **−4** |
| 6 | 輸出尺寸公式記錯 | `O = (N − F)/S + 1` | **`O = (N + 2P − F)/S + 1`** |
| 7 | 忽略通道數 | 「一個核＝一張特徵圖」 | `C_out` 個核、參數要乘 `C_in` |
| 8 | 以為池化有權重 | 給池化算 trainable params | 池化**沒有可學參數**（`count_params() == 0`） |
| 9 | ReLU 只放在最後 | 輸出前放一次 | 每一層卷積之後都要 |
| 10 | 以為 LeNet 用 ReLU + max pool | 「LeNet-5 = ReLU + max pooling」 | 它是 **Sigmoid/Tanh + 平均池化** |
| 11 | 把平移等變說成不變 | 「參數共享 → 平移不變」 | 卷積是**等變**；不變要靠**池化** |
| 12 | 以為卷積就是翻轉核 | 反向要 `rot180(F)` | 深度學習的卷積＝互相關 |
| 13 | 感受野只算核大小 | 「感受野 = F」 | `r_out = r_in + (k−1)·j_in`，要連跳距一起遞推 |
| 14 | depth 由輸入通道決定 | 「輸入 3 通道 → depth 3」 | depth = **濾波器數量**；輸入通道只影響每個核的深度 |
| 15 | ReLU 一半是 0 就是死了 | 「50% 零激活 = 死亡」 | 那是稀疏；死亡是「對所有輸入都輸出 0」 |

**症狀 → 原因**：特徵圖比預期大 → 忘了 `+2P`；比預期小 → stride 記錯；
參數對不上 → 忘了乘 `C_in` 或忘了 bias；邊界被削一圈 → `P=0`；
loss 降不下來 → 卷積後沒 ReLU（整個網路變線性）；訓練好但驗證差 → 參數太多、沒有共享。

## 六、一頁精華（考前 10 分鐘）

```text
【主線】影像（矩陣）→ 卷積（局部＋共享）→ 特徵圖（通道↑ 空間↓）
        → 層層堆疊（邊緣→部件→物件）→ 全連接 → softmax → 類別機率

【三個關鍵字】局部性（只看一小塊）／共享（同一組權重滑全圖）／階層（越深越抽象）

【四個數字】O = (N+2P−F)/S + 1 ；參數 = F²·C_in·C_out + C_out
           乘加 = H_out·W_out·C_out·F²·C_in ；r_out = r_in + (k−1)·j_in

【池化】無參數、降維、空間不變，代價是放棄精確位置
【ReLU】max(0, x)；死亡 = 梯度恆 0、權重永不再更新
【參數量】LeNet 61,706（C5 佔 78%）；deck 模型 1,668,490（Dense(1024) 98.2%）
【FCN】用 Conv2DTranspose 上採樣，才能輸出跟輸入同尺寸的標籤圖
【平移】卷積＝等變；池化＝不變（兩者不是同一件事）
```
