CAM：用 GAP 把「模型在看哪裡」算出來

系列第七篇。上一篇（GAP 是什麼）講 GAP 怎麼把特徵圖壓成一個數；這一篇講它附帶的一個禮物：
因為 GAP 把「一張特徵圖」對應到「一個數」，分類層的權重就可以直接乘回那張圖，變成一張熱圖。
這就是 CAM（Class Activation Mapping）：訊號一路線性，所以「分類權重」與「空間位置」可以相乘。
所有數字都是本機用 NumPy 算的（Python 3.15.1 / NumPy 2.5.4），原始輸出在附錄 G。

1. 一句話：GAP 是那座橋

CAM_c(x, y) = Σ_k w[k, c] · A_k(x, y)
  • A_k：最後一層卷積的第 k 張特徵圖（H × W）
  • w[k, c]：分類層裡「第 k 個通道對類別 c」的權重
  • CAM_c：一張 H × W 的熱圖，值越大代表那個位置越支持類別 c

關鍵在於 w[k, c] 這個權重只綁一個通道，不是綁某個像素。這件事只有 GAP 之後才成立。

2. 網路結構的要求

CAM 原版要求的末端長這樣：

影像 → 卷積層 → 最後一層特徵圖 H × W × K
     → GAP → K 個數
     → Linear(K → C)
     → Softmax → C 個機率
符號意思典型值
K最後一層卷積的通道數512 或 1024
C類別數1,000
H × W特徵圖的空間尺寸7 × 7（224 輸入、32 倍降採樣）

K 這個數字很關鍵：它同時是「GAP 輸出向量的長度」與「熱圖要疊的張數」。C 則是分類層的列數——所以分類權重矩陣是 K × C，每一列就是一個類別對所有通道的重視程度。

3. 數學關係：logit 就是 CAM 的平均

分類層對類別 c 的 logit：

y_c = Σ_k w[k, c] · F_k + b_c          F_k = GAP(A_k) = (1 / H·W) Σ_x Σ_y A_k(x, y)

把 F_k 展開：

y_c = Σ_k w[k, c] · (1 / H·W) ΣΣ A_k(x, y) + b_c
    = (1 / H·W) ΣΣ ( Σ_k w[k, c] · A_k(x, y) ) + b_c
    = (1 / H·W) ΣΣ CAM_c(x, y) + b_c

也就是：

mean(CAM_c) = y_c − b_c

類別分數＝熱圖的空間平均（再平移 bias）。這正是 CAM 能「定位」的原因：把一個純量拆成每個位置的貢獻。

實測兩次：

情況結果
手算例子（3 張 2×2）logit 3.9，mean(CAM) 3.9 ✓
隨機網路（K=6、7×7、C=4）四類的 logit 與 mean(CAM) 最大差 4.44e-16

有 bias 時要記得扣掉：bias = 0.5 → logit 4.40、mean(CAM) 3.90 = logit − bias ✓。所以嚴格說是「logit 減 bias 等於 CAM 平均」，而 bias 不影響熱圖的形狀。

4. 手算一個 CAM

三張 2×2 的特徵圖，權重 0.8 / 0.1 / −0.2：

A₁ = [[10, 0], [8, 2]]      F₁ = 5
A₂ = [[1, 1], [1, 1]]       F₂ = 1
A₃ = [[0, 2], [0, 2]]       F₃ = 1

logit = 0.8×5 + 0.1×1 + (−0.2)×1 = 3.9

逐位置加權相加：

CAM = 0.8·A₁ + 0.1·A₂ − 0.2·A₃
    = [[8.1,  −0.3],
       [6.5,   1.3]]

驗算兩格：

左上 (1,1) = 0.8(10) + 0.1(1) − 0.2(0) = 8.1
右上 (1,2) = 0.8(0)  + 0.1(1) − 0.2(2) = −0.3

四格平均 (8.1 − 0.3 + 6.5 + 1.3) / 4 = 3.9 —— 正好是 logit。

模型會說「左上角最支持狗」（8.1 最大），「右上角反對」（−0.3 最小）。負值不是 bug：它代表那個位置的特徵組合對這個類別是負貢獻。

5. 五個步驟

  1. 前向傳播，把最後一層卷積的 A_1 … A_K 留下來（7 × 7 × K）。
  2. GAP：每張壓成一個數，得到 F_1 … F_K。
  3. 讀權重：從 Linear(K → C) 取出目標類別那一列的 w[1, c] … w[K, c]。
  4. 加權相加：CAM_c = Σ_k w[k, c] · A_k，得到一張 7 × 7。
  5. 上採樣回 224 × 224，疊到原圖上。

第 5 步只是為了「看得出來」：7×7 的熱圖直接看是一格一格的，所以用雙線性插值放大 32 倍。放大不會產生新資訊——它只是把 49 個數字攤開。

6. 為什麼一定要 GAP

末端一列權重綁的是什麼能不能變成熱圖
GAP + Linear(K → C)一個通道（一張特徵圖）可以，w[k, c] 直接乘 A_k
Flatten + Linear(H·W·K → C)一個像素 × 通道不行，權重散在 H×W 個位置上，無法還原成一張圖

實測規模差距（K = 6、7×7、C = 4）：

GAP 頭     : 6 個權重      （每通道每類別一個）
Flatten 頭 : 1,176 個權重  （每像素每通道每類別一個）→ 196 倍

而且那 1,176 個權重結構上就不對應任何一張特徵圖——這不是「比較難算」，是「定義上做不到」。所以傳統 CAM 要求模型末端必須有 GAP；既有模型若沒有，就得改架構重訓。

7. Grad-CAM：用梯度取代權重

α[k, c] = (1 / H·W) ΣΣ ∂y_c / ∂A_k(x, y)          每張特徵圖的平均梯度
M_c     = ReLU( Σ_k α[k, c] · A_k )               熱圖（只保留正貢獻）
項目原始 CAMGrad-CAM
需要 GAP必須不需要
權重來源Linear 層的 w[k, c]logit 對 A_k 的梯度平均
架構限制要改末端並重訓幾乎任何 CNN 都能用
額外成本一次前向前向 + 一次反向

一個可以實測的關係：如果網路真的是「GAP + Linear」，那

∂y_c / ∂A_k(x, y) = w[k, c] / (H·W)      （對位置是常數）
α[k, c]           = w[k, c] / (H·W)
M_c               = ReLU( CAM_c / (H·W) )

實測（K=6、7×7、C=4）：α 與 w/(H·W) 完全相等，M_c 與 ReLU(CAM/(H·W)) 的最大差 5.64e-18。

也就是說：在純 GAP + Linear 的網路上，Grad-CAM 與 CAM 是同一張圖（差一個正規化常數和 ReLU）。只有在中間插了其他層（ReLU、BN、再多一層卷積）之後，梯度才會與權重分道揚鑣——那時 Grad-CAM 仍然可用，CAM 就不行了。

8. 實務上的六個注意

注意為什麼
只反映最後一層熱圖解析度 = 最後特徵圖的解析度（224 → 7×7，放大 32 倍）
上採樣用雙線性最近鄰會出現方塊；雙線性比較平滑，但也更「模糊」
負值要處理顯示時通常 ReLU 或做 min-max 正規化，否則色階被負值吃掉
多類別要逐類算CAM 是「一個類別一張圖」，不是一張通用圖
bias 不影響形狀mean(CAM) = logit − bias，bias 只是整體平移
熱圖不是因果高值只代表「這裡的證據支持該類」，不代表模型「用了」它

9. 六個常見誤解

誤解事實
CAM 需要額外訓練一個模型不用，它只是把既有權重乘回特徵圖
CAM 可以用在任何 CNN原版不行，必須末端是 GAP + Linear（Grad-CAM 才通用）
熱圖數值加起來等於 logit是平均等於 logit − bias，不是總和
熱圖越大代表越準它只反映「模型看哪裡」，不代表答案對；模型可能看錯地方還答對
上採樣可以恢復細節不能，7×7 就只有 49 個值
Grad-CAM 一定比 CAM 好在 GAP + Linear 的網路上兩者等價；Grad-CAM 的價值是「通用」

附錄 B 常見錯誤

  1. 把 A_k 當成「已經 softmax 的機率圖」：它是卷積輸出，值可正可負。
  2. 忘記扣 bias：mean(CAM) 對到的是 logit − bias。
  3. 拿錯權重：要取「目標類別那一列」，不是整張矩陣。
  4. 在 ReLU 之後才取特徵圖：文獻用的是最後一層卷積的線性輸出，取到激活後的圖會偏掉。
  5. 上採樣後直接當遮罩用：熱圖是證據分佈，不是分割結果。
  6. 以為熱圖解釋了「為什麼」：它只顯示「哪裡」，原因仍要另外驗證。
