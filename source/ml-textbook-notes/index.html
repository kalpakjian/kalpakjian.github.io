1. 為什麼我們總是學不會機器學習？

一句話：不是你不夠努力，而是教材的水準與你當前的能力嚴重脫節——中間隔著一道知識鴻溝。對照 PDF 第 2 頁。

1.1 三個症狀（簡報原文）

簡報用一張「斷崖圖」把問題拆成左、中、右三塊：

位置 症狀（原文） 白話翻譯
左 缺乏穩固的數學與理論基礎知識 微積分、線性代數、機率沒補齊就想讀專業書
中 教材水準與學習者當前能力嚴重脫節 書的難度不是「略高於你」，而是「高到斷崖」
右 跳躍式的公式推導與艱澀的學術語言 作者預設你已懂，於是一步跳過三頁推導

注意中間那一塊是核心診斷：左邊與右邊都是它的成因／表現。 數學基礎不足（左）→ 讀者只能勉強跟上；教材又跳躍（右）→ 兩者一夾，就形成「教材水準 ≫ 學習者能力」的落差。

1.2 伊藤真的診斷（簡報引文）

「在沒有準備足夠的基礎知識的情況下就去讀高難度的專業書，當然難以了解其中的內容。」 —— 伊藤真

這句話把責任從「讀者不夠聰明」轉移到難度階梯的設計： 問題不是「你不該讀這本書」，而是「你現在讀的那本書，不是為現在的你寫的」。

1.3 鴻溝的結構：不是努力問題，是斜率問題

讀者狀態 拿到的教材 結果
數學基礎鬆動 高難度專業書（預設微積分流暢） 每一步都卡住，最後放棄
數學基礎鬆動 符合當前水準的橋樑書 補齊地基後再往上走（第 2 章）
數學基礎穩固 高難度專業書 ✅ 這才是那本書預設的讀者

⚠️ 陷阱：把「讀不懂」歸因於「自己不夠努力／不夠聰明」，於是回頭硬啃同一本難書。 簡報的立場很清楚：換書（換難度階梯）比加倍努力更有效。

考點：三個症狀的左／中／右位置與文字要對得上；核心那一句是「教材水準與學習者當前能力嚴重脫節」。 引文作者是 伊藤真，他同時是《最新機器學習的教科書》的作者（見第 11 章）。

3.2 逐項對照表（這就是「1:1」的意思）

數學式 程式碼 說明
tf.sigmoid(tf.matmul(tf.transpose(w), x) + b) 線性組合後過 sigmoid：matmul = 矩陣乘、transpose = 轉置、+ b = 廣播加偏置
tf.reduce_mean(tf.keras.losses.binary_crossentropy(y, y_hat)) binary_crossentropy 回傳逐樣本損失向量，reduce_mean 才把它變成
lambda * tf.nn.l2_loss(w) TF 的 l2_loss(w) 定義就是 ，所以再乘 lambda 即得整項
資料項 正則項 loss = ... + lambda * ... 兩項相加，對應公式中的 +

🔎 最容易誤解的兩點 1. binary_crossentropy 不是一個純量，它是逐樣本的向量；少了 reduce_mean 就不是 。 2. tf.nn.l2_loss(w) 已經自帶 （官方定義為 ）， 所以對應的是 中的 ，不需要自己再除 2。

3.3 本機實測：這兩項真的相等（不是比喻）

本機沒有 TensorFlow，因此我用 numpy 1:1 重建同一條公式，直接驗證「程式碼語意 = 數學式」：

檢查項目 實測結果
資料項 vs reduce_mean(binary_crossentropy) 兩者皆為 0.7771559204，差異 ✅
正則項 vs lambda * tf.nn.l2_loss(w) 兩者皆為 0.0652024658，差異 ✅
總值 0.8423583862（= 0.7771559204 + 0.0652024658）
解析梯度 vs 數值梯度（ 中央差分） 最大差 5.597e-11 ✅

（實測設定： 樣本、 特徵、；完整原始輸出見附錄 G。）

最後一列特別重要：解析梯度與數值梯度吻合到 等級，證明這條 真的是「被最小化的那個目標」， 而不是只是一個看起來很數學的裝飾。

3.4 為什麼「1:1」能救初學者

傳統教材 本書（1:1）
公式一頁、實作在別本書 公式與程式碼並排同一頁
讀者要自己猜「這行公式在程式裡長怎樣」 黃線直接連給你看
數學不好 → 整段放棄 看不懂公式 → 先看程式碼；看不懂程式碼 → 回頭看公式

簡報的收尾語：讓原本晦澀難懂的大學經典教材，在 TensorFlow 與 Keras 的實作下變得簡明流暢。

考點： 對應 lambda * tf.nn.l2_loss(w)（注意 l2_loss 自帶 1/2）； 對應 tf.reduce_mean(...)；σ(...) 對應 tf.sigmoid(...)。 本書的教學法名稱就是「公式與程式碼 1:1 對應」。

9.1 四步驟架構演進（簡報原文）

簡報把模型長大的過程拆成四步，每一步都在前一步上「加一個零件」：

步驟 加了什麼 架構（簡報原文）
Step 1 MINST 資料集導入 ＋ 二層前饋神經網路 MNIST Input → FC 1 → FC 2 → Output
Step 2 ReLU 激活函數與空間篩檢程式 FC 1 → ReLU → Spatial Filter
Step 3 升級為卷積神經網路（CNN） Convolution Layer → ReLU
Step 4 導入池化（Pooling）與 Dropout 防止過擬合 Conv → ReLU → Conv → Pooling (Max Pooling) → Conv → Dropout → ReLU
終點 — Final Output：融合各種特性的高精度辨識網路模型

📌 簡報原文把 MINST／MNIST 兩種拼法混用（Step 1 標題寫 MINST，圖中輸入層寫 MNIST）；正式名稱是 MNIST。

9.2 每個零件「為什麼要加」（不是為了炫技）

零件 解決的問題 不做的後果
FC 層（全連接） 學會特徵的線性組合 什麼都學不到
ReLU 引入非線性，讓多層疊起來有意義 多層退化成一層線性模型
卷積層 用少量權重掃描全圖（參數重用），保留空間結構 全連接層參數爆炸、忽略相鄰像素關係
池化（Max Pooling） 降維、給出局部平移不變性 計算量大、對微小位移敏感
Dropout 訓練時隨機關閉神經元，避免依賴特定神經元 容易過擬合（訓練滿分、測試差）

9.3 本機實測：這四步真的會逐步變好

本機沒有 TensorFlow，因此用 PyTorch 2.14.1 + scikit-learn 內建 load_digits（8×8 手寫數字，1797 筆，完全離線） 實作同一個四步架構，把每一步的測試準確率量出來：

步驟 訓練準確率 測試準確率 參數量
Step 1：FC 兩層（無激活） 1.0000 0.9489 8,970
Step 2：＋ ReLU 激活 1.0000 0.9667 8,970
Step 3：＋ 卷積層（CNN） 1.0000 0.9778 10,410
Step 4：＋ Max Pooling ＋ Dropout 1.0000 0.9800 9,930

測試準確率淨提升（Step 1 → Step 4）= +0.0311（+3.11 個百分點）

三個值得注意的觀察：

  1. 每一步都有貢獻：+ReLU 加 1.78 個百分點、+CNN 再加 1.11、+Pooling/Dropout 再加 0.22——方向與簡報的四步完全一致。
  2. 訓練準確率全是 1.0000：這說明單看訓練分數完全分不出這四個模型的差別，必須看測試分數（呼應節點 6 模型評估）。
  3. 參數量不是單調增加：Step 4 因為池化把特徵圖從 8×8 降到 4×4，參數量反而比 Step 3 少（10,410 → 9,930）——池化就是「用更少參數換更好的效果」。

9.4 程式骨架（PyTorch 版，本機實測可跑）

import torch, torch.nn as nn

class Step4_CNNPoolDropout(nn.Module):
    """Step 4：卷積 + 池化 + Dropout（簡報 p10 的終點架構）"""
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 16, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(2)
        self.drop = nn.Dropout(0.3)
        self.out = nn.Linear(32 * 4 * 4, 10)

    def forward(self, x):
        x = torch.relu(self.conv1(x))                    # Conv -> ReLU
        x = self.pool(torch.relu(self.conv2(x)))         # Conv -> ReLU -> MaxPool
        return self.out(self.drop(x.flatten(1)))         # Dropout -> 全連接輸出

Keras 版本（本書使用的框架，對照閱讀）：

model = keras.Sequential([
    keras.layers.Conv2D(16, 3, padding="same", activation="relu"),
    keras.layers.Conv2D(32, 3, padding="same", activation="relu"),
    keras.layers.MaxPooling2D(2),
    keras.layers.Dropout(0.3),
    keras.layers.Flatten(),
    keras.layers.Dense(10, activation="softmax"),
])

⚠️ 實作細節（自己動手一定會踩） - Dropout 只在訓練時開啟；推論時要用完整網路（PyTorch 用 model.eval()，Keras 由 training 旗標自動處理）。 - 池化後特徵圖尺寸要算對：8×8 --(conv, padding=1)--> 8×8 --(maxpool 2)--> 4×4， 所以全連接層輸入是 32 × 4 × 4（我一開始寫成 32 × 2 × 2，PyTorch 直接丟 RuntimeError: mat1 and mat2 shapes cannot be multiplied (1347x512 and 128x10)）。 - 池化沒有可學參數，卷積層才有（Step 4 比 Step 3 參數少就是這個原因）。

考點：四個步驟的順序與名稱（FC 兩層 → ReLU → CNN → Pooling/Dropout）是必考； 「拒絕給予黑盒子」是本書對這一章的自我要求——每一層都要有數學解釋與 Jupyter 驗證。 記住這組實測方向：每一步都在提升測試準確率，而訓練準確率完全看不出差別。
