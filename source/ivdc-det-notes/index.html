2.1 第一個坑：hasattr 檢查不出 imshow 的問題

hasattr(cv2, "imshow") 會回傳 True，但實際呼叫卻拋出例外：

cv2.error: (-2:Unspecified error) The function is not implemented.
Rebuild the library with Windows, GTK+ 2.x or Cocoa support.

這是因為裝的是 opencv-python-headless，<strong>函式存在、後端沒有實作</strong>。 currentUIFramework() 回傳空字串就是徵兆。修法是換成帶 GUI 的版本：

pip uninstall opencv-python-headless -y
pip install opencv-python

換完之後 UI 框架 顯示 WIN32，imshow 恢復正常。

3. 物件偵測：TensorFlow 版

課程示範使用 TF-Hub 的 SSD MobileNet V2。載入模型與前處理的部分如下：

import tensorflow as tf
import tensorflow_hub as hub
import cv2

MODEL_URL = "https://tfhub.dev/tensorflow/ssd_mobilenet_v2/2"

model = hub.load(MODEL_URL)

image = cv2.imread("image.jpg")
image_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

input_tensor = tf.convert_to_tensor(image_rgb, dtype=tf.uint8)
input_tensor = tf.expand_dims(input_tensor, 0)   # (1, H, W, 3)

推論與取結果的部分，簡報的截圖被遮住了，依標準介面補完：

detections = model(input_tensor)

boxes = detections["detection_boxes"][0].numpy()
scores = detections["detection_scores"][0].numpy()
classes = detections["detection_classes"][0].numpy().astype(int)

<strong>這裡最容易寫錯的是座標格式</strong>：detection_boxes 是歸一化的 0～1， 順序為 ymin, xmin, ymax, xmax，要各自乘上畫面寬高才能畫。

3.1 即時 webcam 版

cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    input_tensor = tf.convert_to_tensor(rgb, dtype=tf.uint8)
    input_tensor = tf.expand_dims(input_tensor, 0)

    detections = model(input_tensor)

    h, w = frame.shape[:2]
    for box, score in zip(detections["detection_boxes"][0].numpy(),
                          detections["detection_scores"][0].numpy()):
        if score < 0.5:
            continue
        ymin, xmin, ymax, xmax = box
        cv2.rectangle(frame, (int(xmin * w), int(ymin * h)),
                      (int(xmax * w), int(ymax * h)), (0, 0, 255), 2)

    cv2.imshow("Detection", frame)
    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

cap.release()
cv2.destroyAllWindows()

4. 物件偵測：PyTorch 版

同一件事換一套框架，差異一目了然。課程示範的模型是 fasterrcnn_resnet50_fpn：

import torch
import torchvision
from torchvision import transforms
from PIL import Image

model = torchvision.models.detection.fasterrcnn_resnet50_fpn(weights="DEFAULT")
model.eval()

image = Image.open("image.jpg").convert("RGB")
transform = transforms.ToTensor()
tensor = transform(image).unsqueeze(0)      # (1, 3, H, W)

with torch.no_grad():
    prediction = model(tensor)[0]

boxes = prediction["boxes"].numpy()
scores = prediction["scores"].numpy()
labels = prediction["labels"].numpy()

跟 TensorFlow 版比，有兩個關鍵差異：

  1. <strong>model.eval() 一定要呼叫</strong>。Faster R-CNN 在 train 模式下回傳的是 loss，不是預測框。
  2. <strong>座標是絕對像素</strong>，順序 [x0, y0, x1, y1]，不需要再乘寬高。

鍵名對照如下，兩套框架一一對應但名稱不同：

TensorFlowPyTorch
detection_boxesboxes
detection_scoresscores
detection_classeslabels

4.1 即時 webcam 版

import cv2
import torchvision
from PIL import Image
from torchvision import transforms

model = torchvision.models.detection.fasterrcnn_resnet50_fpn(weights="DEFAULT")
model.eval()
transform = transforms.ToTensor()

cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    tensor = transform(Image.fromarray(rgb)).unsqueeze(0)

    with torch.no_grad():
        prediction = model(tensor)[0]

    for box, score in zip(prediction["boxes"].numpy(),
                          prediction["scores"].numpy()):
        if score < 0.5:
            break      # 已依分數降序排列
        x0, y0, x1, y1 = [int(v) for v in box]
        cv2.rectangle(frame, (x0, y0), (x1, y1), (0, 255, 0), 2)

    cv2.imshow("PyTorch Detection", frame)
    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

torchvision 的偵測結果已經依信心分數由高到低排序， 所以門檻判斷可以用 break 而不是 continue。

6. 實測：速度與準確度的取捨

課程把這段標題定為即時偵測，但實測並不是每個模型都做得到。 以下數字取自同一台機器、同一個 1280×720 畫面，程式跑在 CPU 上：

模型速度最高信心分數檢出數
fasterrcnn_resnet501.1 FPS0.8304
fasterrcnn_mobilenet5.4 FPS0.9381
fasterrcnn_mobilenet_32024.6 FPS0.1940
ssdlite32019.5 FPS0.3551

<strong>這裡有一個反直覺的結果</strong>：最快的 mobilenet_320 竟然什麼都沒偵測到。 它把輸入縮到 320×320，小目標全部糊掉，加上場景光線偏暗，信心分數最高只有 0.19。 所以快與有用是兩件事，預設值要選在平衡點上。 YOLOv8n 的表現好很多，而且解析度可控：

imgsz速度準確度（官方測試圖）
64037.4 FPSbus 0.87、person 0.87／0.85／0.83
96018.8 FPS中間檔
128011.1 FPS同圖檢出 7 個，小目標更完整

YOLO 在 640 解析度下就有約 37 FPS，比課程示範的 Faster R-CNN 快約 34 倍， 準確度也沒有犧牲。課程標註推薦方案，實測確實如此。 <strong>要注意的另一個陷阱</strong>：用昏暗的室內畫面測 YOLO 也會 0 檢出。 不是所有東西都在 COCO 的 80 個類別裡，洗衣機不在其中， 模型會硬猜成 toilet 或 truck，信心分數自然低。換成官方測試圖就完全正常。

7. CNN 分類：TensorFlow 版

用 MNIST 手寫數字做分類，五個階段。

7.1 載入資料

from tensorflow.keras.datasets import mnist

(x_train, y_train), (x_test, y_test) = mnist.load_data()

print("Training Data Shape:", x_train.shape)   # (60000, 28, 28)
print("Test Data Shape:", x_test.shape)        # (10000, 28, 28)

7.2 前處理

x_train = x_train.reshape(-1, 28, 28, 1) / 255.0
x_test = x_test.reshape(-1, 28, 28, 1) / 255.0

reshape 多出來的那一維是<strong>通道數</strong>。Conv2D 要求輸入為 (H, W, C)， 灰階圖的 C 就是 1。除以 255 是正規化到 0～1。

7.3 建立模型

from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    layers.Conv2D(32, (3, 3), activation="relu", input_shape=(28, 28, 1)),
    layers.MaxPooling2D((2, 2)),
    layers.Conv2D(64, (3, 3), activation="relu"),
    layers.MaxPooling2D((2, 2)),
    layers.Flatten(),
    layers.Dense(128, activation="relu"),
    layers.Dense(10, activation="softmax"),
])

7.4 編譯與訓練

model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"],
)

history = model.fit(
    x_train, y_train,
    epochs=5,
    validation_split=0.1,
)

7.5 單張推論

import numpy as np
import matplotlib.pyplot as plt

index = 0
plt.imshow(x_test[index].reshape(28, 28), cmap="gray")
plt.show()

prediction = model.predict(x_test[index:index + 1])
print("Predicted Class:", np.argmax(prediction))
print("Actual Class:", y_test[index])

np.argmax 取出 10 個機率裡最大的索引，那就是預測的數字。

8. CNN 分類：PyTorch 版

同樣五個階段，換 PyTorch 寫。這段已在本機完整跑完訓練。

8.1 載入資料

import torchvision
import torchvision.transforms as transforms

transform = transforms.ToTensor()

train_dataset = torchvision.datasets.MNIST(
    root="./data", train=True, download=True, transform=transform)
test_dataset = torchvision.datasets.MNIST(
    root="./data", train=False, download=True, transform=transform)

print("Training samples:", len(train_dataset))   # 60000
print("Test samples:", len(test_dataset))        # 10000
print("Image shape:", train_dataset[0][0].shape) # torch.Size([1, 28, 28])

形狀是 (1, 28, 28)，通道在最前面，跟 TensorFlow 的 (28, 28, 1) 相反。 這是兩套框架最根本的差異之一。

8.2 建立模型

import torch
import torch.nn as nn

class CNN(nn.Module):
    def __init__(self):
        super(CNN, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, 3)
        self.pool = nn.MaxPool2d(2, 2)
        self.conv2 = nn.Conv2d(32, 64, 3)
        self.fc1 = nn.Linear(64 * 5 * 5, 128)
        self.fc2 = nn.Linear(128, 10)

    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))
        x = self.pool(torch.relu(self.conv2(x)))
        x = x.view(-1, 64 * 5 * 5)
        x = torch.relu(self.fc1(x))
        x = self.fc2(x)
        return x

<strong>64 × 5 × 5 這個數字怎麼來的</strong>：28 進 3×3 卷積（無 padding）得 26， 池化得 13，再卷積得 11，再池化得 5。所以特徵圖是 64 × 5 × 5。 這個計算是初學者最常卡住的地方。 PyTorch 版<strong>最後一層沒有 softmax</strong>。因為 CrossEntropyLoss 內部已經含 softmax， 再加一次等於算了兩遍。

8.3 訓練

import torch.optim as optim

train_loader = torch.utils.data.DataLoader(
    train_dataset, batch_size=64, shuffle=True)

criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

for epoch in range(5):
    running_loss = 0.0
    for images, labels in train_loader:
        optimizer.zero_grad()
        outputs = model(images)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()
        running_loss += loss.item()
    print(f"Epoch {epoch + 1}/5, Loss: {running_loss / len(train_loader):.4f}")

8.5 單張推論

image, actual_label = test_dataset[0]

with torch.no_grad():
    output = model(image.unsqueeze(0))
    predicted_label = torch.argmax(output, dim=1).item()

print("Predicted Class:", predicted_label)

image.unsqueeze(0) 把 (1, 28, 28) 變成 (1, 1, 28, 28)，也就是加上 batch 維度。 PyTorch 模型永遠吃批次，即使只有一張圖。

9. 兩套框架逐層對照

把兩個版本並排看，這才是這份材料真正的教學重點。

TensorFlow / KerasPyTorch說明
layers.Conv2D(32, (3,3), activation='relu')nn.Conv2d(1, 32, 3) + torch.relu激活函式要自己接
layers.MaxPooling2D((2,2))nn.MaxPool2d(2, 2)等價
layers.Conv2D(64, (3,3), activation='relu')nn.Conv2d(32, 64, 3) + torch.relu等價
layers.Flatten()x.view(-1, 64*5*5)要自己算維度
layers.Dense(128, activation='relu')nn.Linear(64*5*5, 128) + torch.relu等價
layers.Dense(10, activation='softmax')nn.Linear(128, 10)不加 softmax
loss='sparse_categorical_crossentropy'nn.CrossEntropyLoss()後者內建 softmax
optimizer='adam'optim.Adam(lr=1e-3)預設學習率不同
輸入 (28, 28, 1)輸入 (1, 28, 28)通道位置相反
model.fit(...)自己寫訓練迴圈PyTorch 沒有高階 API

三條最值得記住的差異：

  1. **通道位置**：TF 是 (H, W, C)，PyTorch 是 (C, H, W)。
  2. **softmax**：TF 的 Dense(10, activation='softmax') 對應 PyTorch 的

nn.Linear(128, 10) <strong>不加激活</strong>，因為 CrossEntropyLoss 已經內含。

  1. **訓練迴圈**：Keras 一行 fit()，PyTorch 要手寫

zero_grad → forward → loss → backward → step 五步。

10. 四個會讓程式當場掛掉的坑

這些是課程不會告訴你、但實測一定會遇到的。

10.1 攝影機不一定在 index 0

這是最陰險的一個。cv2.VideoCapture(0) <strong>會成功開啟、不會報錯</strong>， 但畫面上是純黑。不會看到任何錯誤訊息，只會覺得怎麼都偵測不到東西。 實測列舉本機攝影機：

索引畫面平均亮度實際狀況
camera 02.4虛擬設備，黑畫面
camera 12.5黑畫面
camera 293～110真正的攝影機

修法是逐個試、看畫面亮度：

def pick_camera(preferred=0, max_index=6, min_brightness=20.0):
    """回傳第一個真的有畫面的攝影機索引。"""
    order = [preferred] + [i for i in range(max_index + 1) if i != preferred]
    for idx in order:
        cap = cv2.VideoCapture(idx, cv2.CAP_DSHOW)
        if not cap.isOpened():
            cap.release()
            continue
        mean = -1.0
        for _ in range(12):          # 等自動曝光穩定
            ok, frame = cap.read()
            if ok and frame is not None:
                mean = float(frame.mean())
        if mean >= min_brightness:
            print(f"using camera {idx} (brightness {mean:.0f})")
            return cap
        cap.release()
        print(f"camera {idx}: black (mean {mean:.1f}) - skip")
    return None

10.3 攝影機剛開的前幾幀不能用

自動曝光需要 1～2 秒才穩定，這段時間的畫面會過曝或全黑。 直接拿去偵測會得到一堆假結果。修法是丟掉前 N 幀：

frames = 0
while True:
    ret, frame = cap.read()
    frames += 1
    if frames <= 10:      # warmup
        continue
    # 開始真正處理

10.4 imshow 沒有 fallback 會直接崩

如果程式跑在 headless 環境（例如考試機、伺服器）， cv2.imshow 會拋出例外，整個程式當場結束。 正確做法是先偵測、不能彈窗就轉成存檔模式：

import numpy as np

def imshow_available():
    try:
        cv2.imshow("__probe__", np.zeros((4, 4, 3), np.uint8))
        cv2.waitKey(1)
        cv2.destroyWindow("__probe__")
        return True
    except Exception:
        return False

show_gui = imshow_available()
# 之後用 if show_gui: cv2.imshow(...) 包起來
